- 구현 파일: `../01_recursion_A.c`, `../01_recursion_B.c`, `../01_recursion_C.c`
- 관련 교수님 자료: [실습 2 — 순환](../../practice_board/posts/3_실습_2_순환_4주차_오프라인_실습.md)
- 이 문서의 소문제는 **서로 독립**입니다. 하나씩 골라 구현하고, 입력·출력 형식도 해당 문제에 맞춰 테스트하세요.
- 정답 코드와 풀이 알고리즘은 넣지 않았습니다.

## A. 1부터 N까지의 합

정수 `N`이 주어집니다. `1 + 2 + … + N`을 **재귀 함수**로 계산해 출력하세요. `N=0`이면 합은 0입니다.

### 입력

`0 ≤ N ≤ 1,000`인 정수 하나가 주어집니다.

### 출력

1부터 N까지의 합을 출력합니다.

### 예제

입력:
```text
10
```
출력:
```text
55
```

## B. 거듭제곱

정수 `x`와 0 이상의 정수 `n`이 주어집니다. `x^n`을 **재귀 함수**로 계산해 출력하세요.

### 입력

공백으로 구분된 `x`, `n`이 주어집니다. `-10 ≤ x ≤ 10`, `0 ≤ n ≤ 10`이고, 결과는 부호 있는 64비트 정수 범위 안에 있습니다.

### 출력

`x^n`을 출력합니다. `n=0`일 때 결과는 1입니다.

### 예제

입력:
```text
2 10
```
출력:
```text
1024
```

## C. 문자열 뒤집기

한 줄의 문자열을 입력받아 문자의 순서를 반대로 출력하세요. **재귀를 사용해야 합니다.** 공백과 문장부호도 입력에 포함될 수 있습니다. 입력은 ASCII 문자로만 주어집니다.

### 입력

길이 1~100인 한 줄이 주어집니다.

### 출력

입력 문자열을 뒤집어 출력합니다.

### 예제

입력:
```text
Hello world!!!
```
출력:
```text
!!!dlrow olleH
```

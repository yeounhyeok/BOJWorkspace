## A. 선택 정렬

정수 배열을 오름차순으로 정렬하세요. 정렬은 직접 **선택 정렬**로 구현하고, 두 원소를 교환할 때는 호출한 쪽의 값도 실제로 바뀌도록 포인터를 사용하는 `swap` 함수를 작성해 사용하세요. 라이브러리 정렬 함수는 사용할 수 없습니다.

### 입력

첫 줄에 원소 개수 `N`이 주어지고, 다음 줄에 정수 `N`개가 주어집니다. `1 ≤ N ≤ 1,000`, 각 원소의 절댓값은 1,000,000 이하입니다.

### 출력

정렬된 수열을 한 줄에 공백으로 구분해 출력합니다.

### 예제

입력:
```text
5
64 25 12 22 11
```
출력:
```text
11 12 22 25 64
```

### 직접 확인할 입력

이미 정렬된 배열, 역순 배열, 중복 원소가 있는 배열, 원소가 하나뿐인 배열을 각각 시험하세요. 또 `x=4`, `y=5`를 `swap`한 뒤 두 변수의 값이 실제로 바뀌는지 확인하세요.

## B. 포인터로 결과 전달하기

정수 `x`, `y`를 입력받고, `add` 함수가 두 수의 합을 계산해 **포인터 매개변수로 전달된 결과 칸**에 저장하도록 구현하세요.

### 입력 / 출력

정수 두 개를 입력받아 그 합을 출력합니다. 예를 들어 입력이 `4 5`이면 출력은 `9`입니다.

## C. 포인터 추가 연습 — 교수님 실습 5

아래 과제는 서로 독립적으로 구현하세요.

1. 정수 10개를 동적 메모리에 저장한 뒤, 함수에 포인터로 전달해 합계를 구하고 메모리를 해제합니다.
2. 공백 없는 문자열 두 개를 입력받아, 새로 할당한 메모리에 이어 붙인 결과를 출력하고 해제합니다.
3. 문자열 두 개가 들어 있는 배열과 인덱스 `0` 또는 `1`이 주어집니다. 포인터가 해당 문자열을 가리키게 한 뒤 그 문자열을 출력합니다.

원문 과제는 위에 연결한 교수님 실습 5 게시글에서 확인할 수 있습니다.

## D. 이중 포인터 통합 연습 — C의 3번 보강

공백 없는 문자열 두 개 `s1`, `s2`와 정수 `idx`(`0` 또는 `1`)가 주어집니다. 아래 세 함수를 **모두 `char **` 매개변수로** 구현해 순서대로 사용하세요. (`char *`로 받아서 되는 풀이는 인정하지 않습니다. 정답 코드는 없습니다.)

1. `make_string(&a, s1)`, `make_string(&b, s2)` — 입력 길이에 맞게 `malloc`한 메모리에 문자열을 복사하고, 그 주소를 `main`의 `char *a`, `char *b`에 **저장**합니다. 반환값으로 주소를 돌려주는 방식은 쓰지 않습니다.
2. `swap_ptr(&a, &b)` — 문자열 내용은 건드리지 않고 `a`와 `b`가 가리키는 대상만 서로 바꿉니다.
3. `set_pointer(&p, a, b, idx)` — `idx`가 `0`이면 `p`가 `a`가 가리키는 문자열을, `1`이면 `b`가 가리키는 문자열을 가리키게 합니다. 복사하지 말고 **가리키게만** 합니다.

### 입력

첫 줄에 `s1`, `s2`가 공백으로 구분되어 주어지고, 둘째 줄에 `idx`가 주어집니다. 문자열 길이는 1~100입니다.

### 출력

첫째 줄에 `p`가 가리키는 문자열, 둘째 줄에 `a`, `b`를 공백으로 구분해 출력합니다. 마지막에 `a`, `b`를 각각 한 번씩만 `free`하세요. (`p`는 `free`하지 않습니다.)

### 예제

입력:
```text
hello world
0
```
출력:
```text
world
world hello
```

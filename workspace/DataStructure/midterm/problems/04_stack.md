# 문제 04 — 배열 스택 명령 처리

- 구현 파일: `../04_stack.c` (현재 빈 파일)
- 관련 교수님 자료: [실습 6 — 스택](../../practice_board/posts/7_실습_6_스택.md)
- 정답 코드는 없습니다. C++의 `std::stack` 같은 완성 컨테이너 대신 배열과 인덱스로 스택을 직접 구현하세요.

정수 스택에 명령을 차례로 수행하고, 값을 출력해야 하는 명령의 결과를 출력하세요. 스택의 최대 크기는 명령 개수 `N`으로 잡아도 충분합니다.

## 입력

첫 줄에 명령 개수 `N`이 주어집니다. 다음 `N`줄에는 아래 명령 중 하나가 주어집니다.

- `push X`: 정수 X를 스택에 넣습니다. 출력하지 않습니다.
- `pop`: 맨 위 값을 제거하고 출력합니다. 비어 있으면 `-1`을 출력합니다.
- `top`: 맨 위 값을 출력합니다. 비어 있으면 `-1`을 출력합니다.
- `size`: 원소 개수를 출력합니다.
- `empty`: 비어 있으면 `1`, 아니면 `0`을 출력합니다.

`1 ≤ N ≤ 100,000`, `X`는 32비트 부호 있는 정수 범위입니다.

## 출력

`pop`, `top`, `size`, `empty` 명령의 결과를 각각 한 줄에 출력합니다.

## 예제

입력:
```text
10
push 5
push 2
top
size
pop
empty
pop
push 7
top
size
```
출력:
```text
2
2
2
0
5
7
1
```

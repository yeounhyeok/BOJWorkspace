# 문제 03 — 동적 메모리로 학생 정보 정렬

- 구현 파일: `../03_dynamic_memory.c` (현재 빈 파일)
- 관련 교수님 자료: [실습 4 — 동적 메모리 할당](../../practice_board/posts/5_실습_4_동적_메모리할당_6주차_오프라인_실습.md)
- 정답 코드는 없습니다.

학생 4명의 이름, 키, 몸무게를 입력받아 이름의 사전식 오름차순으로 정렬한 뒤 출력하세요. 학생 정보는 구조체로 묶고, **학생 배열 공간을 동적 할당**해야 합니다. 크기가 정해진 일반 배열 `student_info students[4]`만으로 해결하지 마세요.

이름 비교는 C 문자열 기준으로 합니다. 테스트가 일관되도록 이름은 공백 없는 영문 ASCII 문자열로 입력합니다.

## 입력

첫 줄에는 학생 수 `N`이 주어집니다. 이 문제에서는 `N=4`입니다. 다음 `N`개 줄에 `이름 키 몸무게`가 주어집니다.

- 이름: 길이 1~9, 공백 없음
- 키: 100~230
- 몸무게: 소수 첫째 자리까지

## 출력

이름 오름차순으로 정렬된 학생 정보를 한 줄에 하나씩 `이름 키 몸무게` 형식으로 출력하세요. 몸무게는 소수 첫째 자리까지 출력합니다.

## 예제

입력:
```text
4
Lee 172 83.4
Hong 167 72.5
Kim 159 70.8
Yu 163 58.4
```
출력:
```text
Hong 167 72.5
Kim 159 70.8
Lee 172 83.4
Yu 163 58.4
```

## 구현 조건

- 학생 정보 구조체를 정의합니다.
- 학생 수에 맞는 저장 공간을 동적으로 할당하고, 사용이 끝나면 해제합니다.
- 이름 비교로 정렬합니다.
- 메모리 할당이 실패하는 경우도 확인합니다.

## 추가 연습

교수님 게시글의 두 번째 과제인 UP/DOWN 게임을 확장해, 사용자가 입력한 숫자들을 동적으로 할당한 배열에 저장하고 정답을 맞힌 뒤 입력 기록을 출력해 보세요.

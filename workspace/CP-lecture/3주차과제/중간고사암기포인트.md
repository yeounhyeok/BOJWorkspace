## 0. 빠른 복습 체크리스트

- 프로그램은 컴퓨터에게 시킬 일을 적은 **명령어들의 집합체**다.
- 컴파일러는 C 소스 코드를 컴퓨터가 실행할 수 있는 **기계어**로 바꾼다.
- C언어는 데니스 리치가 UNIX 운영체제 개발을 위해 만들었다.
- C언어의 장점: 간결함, 효율성, 저수준/고수준 프로그래밍 가능, 이식성.
- C언어의 단점: 초보자가 배우기 어렵고, 자료형/포인터/메모리 관리 실수가 치명적일 수 있음.
- 알고리즘은 문제를 해결하기 위한 절차다.
- C 개발 과정: 소스 파일 작성 -> 컴파일 -> 실행.
- `if`, `switch`, 자료형 변환, 상수 표현, 출력 형식 지정자는 시험 전에 꼭 확인.

## 3. 자료형과 출력 형식 지정자

### 정수형

| 자료형 | 출력 형식 |
|---|---|
| `short` | `%hi` |
| `int` | `%d` |
| `long` | `%ld` |
| `long long` | `%lld` |
| `unsigned int` | `%u` |
| `unsigned long` | `%lu` |
| `unsigned long long` | `%llu` |

### 실수형

| 자료형 | 출력 형식 | 유효 숫자 메모 |
|---|---|---|
| `float` | `%f` | 약 6자리 |
| `double` | `%lf` | 약 16자리 |
| `long double` | `%Lf` | 약 16자리 이상 |

### 표시 형식 지정자

```c
%nn.mmf
```

- `nn`: 전체 출력 칸 수
- `mm`: 소수점 아래 자릿수
- 예: `printf("%8.2f", 3.14159);`
  - 전체 8칸 확보
  - 소수점 아래 2자리 출력

## 4. 상수 정리

### 정수 상수

- 기본 정수: `10`, `100`, `1234`
- 접미사를 붙여 자료형을 명확히 할 수 있음

| 예시 | 의미 |
|---|---|
| `10U` | unsigned int |
| `10L` | long |
| `10UL` | unsigned long |
| `10ULL` | unsigned long long |

### 기호 상수

```c
#define MAX 100
```

```c
const int MAX = 100;
```

- `#define`: 전처리 단계에서 이름을 값으로 치환
- `const`: 값을 바꿀 수 없는 변수처럼 사용

### 부동소수점 상수

- 소수점이 들어가면 실수 상수로 본다.
- 지수 표기법도 가능하다.

```c
3.14
1.2e3   // 1.2 * 10^3 = 1200
5.0e-2  // 5.0 * 10^-2 = 0.05
```

## 5. 수업 중 나온 핵심 문법 포인트

### 5-1. 연쇄 대입과 형변환

```c
#include <stdio.h>

int main(){
    int x;
    float y;

    y = x = 2.5;

    printf("%d %f", x, y);
    return 0;
}
```

### 실행 흐름

1. `x = 2.5`가 먼저 실행된다.
2. `x`는 `int`이므로 `2.5`가 `2`로 잘린다.
3. 그 다음 `y = x`가 실행된다.
4. `y`에는 이미 잘린 값인 `2`가 들어간다.

### 출력 결과 감각

```text
2 2.000000
```

### 핵심

- 연쇄 대입은 오른쪽에서 왼쪽으로 진행된다.
- 중간에 `int` 변수에 들어가면 소수 부분이 손실될 수 있다.
- `float y`라고 해서 원래 `2.5`가 보존되는 것이 아니다.

---

### 5-2. 16진수 표현

```c
#include <stdio.h>

int main(){
    int x = 0x10;
    printf("%d", x);
    return 0;
}
```

### 핵심

- `0x`로 시작하면 16진수다.
- `0xF`는 10진수로 15다.
- `0x10`은 10진수로 16이다.

### 외우기

```text
0xF  = 15
0x10 = 16
```

## 6. 조건문 시험 포인트

### if문

```c
if (조건식) {
    조건식이 참일 때 실행;
}
```

```c
if (조건식) {
    참일 때 실행;
} else {
    거짓일 때 실행;
}
```

### 공부 포인트

- 조건식 결과가 참이면 `if` 블록 실행
- 조건식 결과가 거짓이면 `else` 블록 실행
- 비교 연산자와 대입 연산자 혼동 주의

```c
if (x == 10)  // 비교
if (x = 10)   // 대입, 실수하기 쉬움
```

## 7. switch문 시험 포인트

```c
switch (값) {
case 1:
    printf("one");
    break;
case 2:
    printf("two");
    break;
default:
    printf("other");
    break;
}
```

### 핵심

- `switch`는 값에 맞는 `case`로 이동한다.
- `break`가 없으면 다음 `case`까지 계속 실행될 수 있다.
- 이 현상을 fall-through라고 한다.

### 꼭 기억

```text
switch문은 break를 확인해야 한다.
```

## 8. 시험 전 한 줄 암기

- C 개발 과정은 소스 작성 -> 컴파일 -> 실행이다.
- `float`는 `%f`, `double`은 `%lf`, `int`는 `%d`로 출력한다.
- `y = x = 2.5`에서 `x`가 `int`면 `2.5`가 `2`로 손실된다.
- `0xF = 15`, `0x10 = 16`이다.
- `switch`에서 `break`가 없으면 다음 `case`까지 실행될 수 있다.
- `#define 이름 값` 또는 `const int 이름 = 값`으로 기호 상수를 만들 수 있다.

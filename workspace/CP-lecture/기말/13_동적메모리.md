# 13장 동적 메모리 (Dynamic Memory) ★ = 네가 말한 "동적할당"

> 예제 코드: [src/13_동적메모리/](src/13_동적메모리/)

## 1. 왜 동적 할당인가
- 정적 배열 `int a[100];` 은 **컴파일 시 크기 고정** → 너무 작으면 부족, 너무 크면 낭비.
- **동적 할당**: 프로그램 **실행 중에** 필요한 만큼 메모리를 잡음 (힙 영역).

## 2. malloc / free 4단계 패턴 ★★★
```c
#include <stdlib.h>
int *p = (int *)malloc(개수 * sizeof(int));  // ① 할당 (+형변환)
if (p == NULL) { printf("할당 오류"); exit(1); } // ② NULL 검사
... p[i] 사용 ...                              // ③ 사용 (배열처럼)
free(p);                                       // ④ 해제 (★ 안 하면 누수)
```
| 함수 | 역할 |
|------|------|
| `malloc(바이트수)` | 메모리 할당, **시작 주소 반환** (실패 시 NULL) |
| `free(p)` | 할당한 메모리 반납 |
| `sizeof(자료형)` | 자료형 1개의 바이트 크기 |

- ⚠️ 외울 4가지: **(자료형*)형변환 / 개수×sizeof / NULL검사 / free**
- [malloc1.c](src/13_동적메모리/malloc1.c) : `char` 1개 동적 할당 (가장 단순)
- [malloc2.c](src/13_동적메모리/malloc2.c) : `int` 5개 = `malloc(5*sizeof(int))`

## 3. 동적 배열
- [dyn_array.c](src/13_동적메모리/dyn_array.c) ★ : 사용자가 **입력한 개수만큼** 배열 생성
```c
scanf("%d", &items);
p = (int*)malloc(sizeof(int)*items);  // 실행 중 크기 결정!
for(i=0;i<items;i++) ... p[i] ...
```
- [dyn_array2.c](src/13_동적메모리/dyn_array2.c) : 큰 배열 동적 할당 후 사용 → free

## 4. 동적 구조체 (★ 연결 리스트의 기초)
- [malloc4.c](src/13_동적메모리/malloc4.c) : `struct Book *p = (struct Book*)malloc(sizeof(struct Book));` → `p->number`, `p->title` (포인터니까 `->`)
- [dyn_struct.c](src/13_동적메모리/dyn_struct.c) ★ : `struct movie` 를 동적 배열로 여러 개 할당
```c
struct movie *p = (struct movie*)malloc(n * sizeof(struct movie));
p[i].rating ...   // 또는 (p+i)->rating
```
  - 이게 **연결 리스트(노드 동적 생성)** 의 토대.

## 📝 연습 문제 (게시판)
- **미니프로젝트 (연결 리스트 만들어 보기)** — 노드를 `malloc` 으로 만들어 연결.
  - ⚠️ 이 글은 게시판에서 로그인해야 보이는지 본문/모범답안을 못 가져왔어.
  - 대신 [dyn_struct.c](src/13_동적메모리/dyn_struct.c) + [malloc4.c](src/13_동적메모리/malloc4.c) 로 "동적 구조체 → 노드" 개념을 잡으면 됨.
  - 연결 리스트 노드 기본형 (참고):
    ```c
    struct node { int data; struct node *next; };
    struct node *p = (struct node*)malloc(sizeof(struct node));
    p->data = 10;  p->next = NULL;
    ```

## 🎯 시험 포인트 요약
- 정적 배열 vs 동적 할당 차이 (크기 결정 시점)
- **malloc 4단계: (형변환) + 개수×sizeof + NULL검사 + free**
- `malloc` 반환형은 `void*` → 형변환 필요, 실패 시 NULL
- 동적 구조체는 포인터라 멤버 접근에 `->` 사용
- `free` 안 하면 메모리 누수(memory leak)

# 🎯 기말고사 출제 하네스 (8~14장)

중간고사 때 쓰던 방식([../중간고사때공부하던방식/](../중간고사때공부하던방식/))을 **기말 범위(8~14장)** 로 옮긴 거야.
"출제 → 풀기 → 채점" 3단계를 반복하면서 공부하는 구조.

## 📂 파일
| 파일 | 역할 |
|------|------|
| [instructions.md](instructions.md) | **출제 프롬프트** (핵심). AI에게 주면 기말 모의고사 8문제(30점)를 생성 |
| [example_term.md](example_term.md) | 위 프롬프트로 만든 **모의고사 예시** (문제 + 정답·해설·부분점수). 바로 풀어봐도 됨 |
| [채점_instructions.md](채점_instructions.md) | **채점 프롬프트**. 손글씨 답안 사진/텍스트를 주면 부분점수까지 채점 |

## 🔁 사용법 (3단계 루프)

**1) 출제** — 새 모의고사가 필요하면 AI(Claude 등)에게:
> [instructions.md](instructions.md) 내용을 그대로 주면서 "이 지침대로 기말 모의고사 만들어줘"

→ 매번 다른 8문제 세트가 나옴. (이미 만들어둔 [example_term.md](example_term.md) 로 시작해도 됨)

**2) 풀기** — 정답/해설 부분은 가리고, 시험지처럼 30~50분 손으로 풀기.

**3) 채점** — 푼 답안을 사진 찍거나 타이핑해서 AI에게:
> [채점_instructions.md](채점_instructions.md) + 모의고사 + 내 답안 을 주고 "채점해줘"

→ `총점 / 30`, 문제별 점수표, 핵심 오답 정리, 다음에 볼 것까지 나옴 (중간고사 [채점결과.md](../중간고사때공부하던방식/채점결과.md) 와 같은 형식).

## 📐 시험 스펙 (instructions.md 기준 — 실제 기말 본 선배 제보 반영)
- 범위: **8~14장** (함수·포인터·문자열·구조체·파일입출력·동적메모리·전처리/매크로)
- **8문제 / 30점 / 필답 / 부분점수**
- **출제 비중**: 포인터(킬러 포함) ≫ 함수·문자열·구조체 > 파일입출력·동적메모리·전처리(저비중)
- 권장 배치: 종합출력예측(3) · **포인터 킬러(5)** · 포인터 swap(4) · 함수 static(4) · 문자열(4) · 구조체(4) · 버그찾기(3) · 경량개념[파일/동적/전처리](3)
- 필수 포함: **① 포인터 킬러 ② 코드 출력값 예측(종합) ③ 버그 찾기** + 포인터 swap, 구조체
- 저비중 처리: 파일입출력·동적메모리·전처리는 합쳐서 가벼운 1문제로만 (선배 제보상 거의 안 나옴 — 단, 제보가 100% 보장은 아니라 완전히 빼진 않음)

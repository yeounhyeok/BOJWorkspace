## 문제

### 1번. 종합 - 코드 보고 예상 출력값 쓰기 [3점]

다음 C 코드의 출력 결과를 **네 줄 모두** 쓰시오. 특히 `*(p + 1)`과 `*p + 1`이 왜 다른지 한 줄로 설명하시오.

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char c = 'C';
    int a[3] = {10, 20, 30};
    int *p = a;
    char s[] = "hello";

    printf("%d\n", c);
    printf("%d\n", *(p + 1));
    printf("%d\n", *p + 1);
    printf("%d\n", (int)strlen(s));

    return 0;
}
```

### 2번. ★ 포인터 킬러 - 포인터 + 배열 + 함수 [5점]

다음 C 코드의 출력 결과를 쓰고, (1) 함수에 `data`만 넘겼는데 `main`의 배열 값이 바뀌는 이유, (2) `&max`와 함수 안의 `*maxOut`이 하는 일을 설명하시오.

```c
#include <stdio.h>

void process(int *arr, int n, int *maxOut)
{
    int i;
    *maxOut = arr[0];
    for (i = 0; i < n; i++) {
        arr[i] = arr[i] * 2;
        if (arr[i] > *maxOut)
            *maxOut = arr[i];
    }
}

int main(void)
{
    int data[4] = {3, 1, 4, 2};
    int max;

    process(data, 4, &max);

    for (int i = 0; i < 4; i++)
        printf("%d ", data[i]);
    printf("\nmax=%d\n", max);

    return 0;
}
```

### 4번. 함수 - static 변수 출력 예측 [4점]

다음 C 코드의 출력 결과를 쓰고, `total`이 그렇게 변하는 이유를 `static` 키워드와 함께 설명하시오.

```c
#include <stdio.h>

int accumulate(int x)
{
    static int total = 0;
    total += x;
    return total;
}

int main(void)
{
    printf("%d\n", accumulate(10));
    printf("%d\n", accumulate(20));
    printf("%d\n", accumulate(5));
    return 0;
}
```

### 7번. ★ 버그 찾기 - 무엇이 잘못되었는가 [3점]

## 정답 및 해설

### 1번 정답 및 해설 [3점]

출력 결과:

```text
67
20
11
5
```

해설:

- `c = 'C'`를 `%d`로 출력하면 문자의 아스키 코드 값 `67`이 나온다.
- `*(p + 1)`은 `a[1]`이므로 `20`. (포인터 + 1은 다음 원소)
- `*p + 1`은 `(*p) + 1`이다. `*`가 `+`보다 우선이라 먼저 `a[0]=10`을 꺼낸 뒤 `1`을 더해 `11`.
- `strlen("hello")`는 널 문자를 뺀 길이 `5`.
- 즉 `*(p+1)`은 "다음 원소의 값", `*p+1`은 "현재 값 + 1"로 의미가 다르다.

부분 점수 기준:

- 네 줄 출력(67, 20, 11, 5) 정확: 2점 (한 줄당 0.5점)
- `*(p+1)`과 `*p+1`의 차이(연산자 우선순위) 설명: 1점

---

### 2번 정답 및 해설 [5점]

출력 결과:

```text
6 2 8 4 
max=8
```

해설:

- `process`는 `arr`로 배열의 **주소**를 받는다. 배열을 함수에 넘기면 주소가 전달되므로, 함수 안에서 `arr[i] = arr[i] * 2`로 바꾸면 `main`의 `data` 원본이 그대로 바뀐다. → `{3,1,4,2}`가 `{6,2,8,4}`가 된다.
- `*maxOut = arr[0];`로 시작값을 첫 원소(3)로 잡고, 두 배로 만든 값들과 비교하며 최댓값을 갱신한다. i=0에서 6, i=2에서 8 → 최종 `max=8`.
- `&max`는 `main` 변수 `max`의 주소를 넘기는 것이고, 함수 안의 `*maxOut`은 그 주소가 가리키는 원본(`max`)에 값을 써넣는 것이다. (출력 매개변수)

부분 점수 기준:

- 배열 출력 `6 2 8 4` 정확: 1.5점
- `max=8` 정확: 1점
- 배열을 넘기면 주소가 전달되어 원본이 바뀐다는 설명: 1.5점
- `&max` / `*maxOut`이 원본에 결과를 돌려주는 역할이라는 설명: 1점

---

### 3번 정답 및 해설 [4점]

정답 예시:

```c
#include <stdio.h>

void swap(int *px, int *py)
{
    int tmp = *px;
    *px = *py;
    *py = tmp;
}

int main(void)
{
    int a = 100, b = 200;
    swap(&a, &b);
    printf("a=%d b=%d\n", a, b);   // a=200 b=100
    return 0;
}
```

해설:

- 호출 시 `swap(&a, &b)`로 주소를 넘기고, 함수 안에서 `*px`, `*py`로 원본에 접근해 교환하므로 값이 실제로 바뀐다.
- `void swap(int x, int y)`처럼 값으로 받으면 복사본만 교환되어 함수가 끝나면 원본은 그대로다.

부분 점수 기준:

- 매개변수를 포인터(`int *px, int *py`)로 선언: 1점
- `tmp`를 이용한 교환 로직이 `*px`, `*py`로 정확: 1.5점
- `main`에서 `swap(&a, &b)`로 주소 전달: 1점
- call by value로는 원본이 안 바뀌는 이유 설명: 0.5점

### 4번 정답 및 해설 [4점]

출력 결과:

```text
10
30
35
```

해설:

- `total`은 `static` 변수라 함수가 끝나도 사라지지 않고 값이 유지되며, 초기화(`= 0`)는 처음 한 번만 된다.
- 그래서 호출할 때마다 `10 → 30(10+20) → 35(30+5)`로 누적된다.
- 만약 `static`이 없는 일반 지역 변수였다면 매번 `0`으로 초기화되어 `10, 20, 5`가 나왔을 것이다.

부분 점수 기준:

- 세 줄 출력(10, 30, 35) 정확: 2점
- `static` 변수가 값을 유지한다는 설명: 1.5점
- 일반 지역 변수와의 차이 언급: 0.5점

### 5번 정답 및 해설 [4점]

출력 결과:

```text
0
HelloWorld
10
```

해설:

- `strcmp(s1, "Hello")`는 두 문자열이 같으므로 `0`.
- `strcat(s1, p)`로 `s1`은 `"HelloWorld"`가 된다. (`s1`의 크기가 20이라 공간 충분)
- 길이는 `10`.
- (1) `strcmp`는 같으면 `0`, 다르면 사전순에 따라 음수/양수. (참=1이 아님)
- (2) `char s1[20] = "Hello"`는 배열에 복사된 것이라 `s1[0] = 'h';`처럼 **수정 가능**. `char *p = "World"`는 읽기 전용 문자열 상수를 가리켜서 `p[0] = 'w';`를 하면 **실행 중 오류**가 난다. (단, `p = "다른문자열";`처럼 가리키는 대상을 바꾸는 건 가능)

부분 점수 기준:

- 세 줄 출력(0, HelloWorld, 10) 정확: 2점
- `strcmp`가 같을 때 0 반환 설명: 1점
- `char s1[]`(수정 가능) vs `char *p`(수정 불가) 차이 설명: 1점

### 6번 정답 및 해설 [4점]

정답 예시:

```c
#include <stdio.h>

struct book {
    char title[30];
    int price;
};

int main(void)
{
    struct book list[3] = {
        {"C",      20000},
        {"Java",   18000},
        {"Python", 25000}
    };
    int i, min = 0;

    for (i = 1; i < 3; i++) {
        if (list[i].price < list[min].price)
            min = i;
    }
    printf("%s\n", list[min].title);   // Java

    return 0;
}
```

추가 문장:

```c
struct book *p = &list[0];
printf("%d\n", p->price);   // 20000
```

해설:

- 구조체 변수는 멤버를 `.`로 접근한다: `list[i].price`, `list[min].title`.
- 가장 싼 책은 `Java`(18000)이다.
- `p`는 **구조체 포인터**라서 `p.price`가 아니라 `p->price`로 접근한다. `p->price`는 `(*p).price`와 같다.

부분 점수 기준:

- 구조체 선언(멤버 2개) 정확: 1점
- 구조체 배열 선언/초기화: 0.8점
- 최솟값 가격을 찾는 반복/비교 로직: 1.2점
- 결과 제목 출력(`list[min].title`): 0.5점
- `p->price` 문장과 `->`를 쓰는 이유(포인터라서) 설명: 0.5점

### 7번 정답 및 해설 [3점]

무엇이 잘못되었나:

- `addTen(int x)`는 값을 **복사본**으로 받는다(call by value). 함수 안에서 `x`를 바꿔도 `main`의 `n`은 그대로다. 그래서 `5`가 출력된다.

올바르게 고친 코드:

```c
#include <stdio.h>

void addTen(int *x)      // 포인터로 받고
{
    *x = *x + 10;        // 주소가 가리키는 원본을 변경
}

int main(void)
{
    int n = 5;
    addTen(&n);          // 주소를 넘김
    printf("%d\n", n);   // 15
    return 0;
}
```

부분 점수 기준:

- 원인을 call by value(복사본만 바뀜)로 정확히 설명: 1.5점
- 매개변수를 포인터로 바꾸고 `*x`로 원본 수정: 1점
- 호출을 `addTen(&n)`으로 주소 전달하도록 수정: 0.5점

### 8번 정답 및 해설 [3점]

(1) 출력 결과:

```text
9
```

해설:

- 매크로는 단순 텍스트 치환이라 `DOUBLE(3) * 2`는 `3 + 3 * 2`로 바뀐다. 곱셈이 먼저라 `3 + 6 = 9`이다. (학생이 기대한 `(3+3)*2 = 12`가 아님)
- 의도대로(=12) 만들려면 매크로 전체를 괄호로 감싼다:

```c
#define DOUBLE(x) ((x) + (x))
```

  이러면 `DOUBLE(3) * 2`가 `((3)+(3)) * 2 = 12`가 된다.

(2) 정답 예시:

```c
int *p = (int *)malloc(10 * sizeof(int));   // 동적 할당
...
free(p);                                     // 해제
```

부분 점수 기준:

- (1) 출력 `9` 정확 + 이유(텍스트 치환/우선순위) 설명: 1점
- (1) `((x)+(x))`로 괄호 씌우는 수정안 제시: 1점
- (2) `malloc(10 * sizeof(int))` + `(int *)` 형변환, `free(p)`: 1점

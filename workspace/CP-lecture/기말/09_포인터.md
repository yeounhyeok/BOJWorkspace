# 9장 포인터 (Pointers) ★ 기말 최중요

> 예제 코드: [src/09_포인터/](src/09_포인터/)
> 9장 미니프로젝트(어드벤처 게임)가 **기말 과제 게임의 기반**이라 게시판에 명시됨.

## 1. 주소와 포인터 기본 ★★
- 모든 변수는 메모리의 어떤 **주소(address)** 에 저장됨.
- `&변수` : 그 변수의 **주소**를 구함 (주소 연산자)
- `자료형 *p;` : 주소를 저장하는 변수 = **포인터**
- `*p` : 포인터가 가리키는 곳의 **값** (간접 참조, dereference)

```c
int number = 10;
int *p;          // int를 가리키는 포인터
p = &number;     // p 에 number의 주소 저장
printf("%d", *p);// 10  (p가 가리키는 값)
*p = 20;         // number 가 20 으로 바뀜!
```
- [address_of.c](src/09_포인터/address_of.c) : `&i, &c, &f` 로 변수 주소 출력
- [pointer1.c](src/09_포인터/pointer1.c) : 주소(`&number`, `p`) vs 값(`number`, `*p`) 한눈에 비교
- [pointer2.c](src/09_포인터/pointer2.c) ★ : `*p = 20;` 으로 **원본 변수 값을 바꿈** (포인터의 핵심 능력)

> 헷갈림 주의: 선언할 때 `int *p` 의 `*`는 "포인터 선언" 표시이고, 사용할 때 `*p` 의 `*`는 "값 꺼내기"임.

## 2. call by value vs call by reference ★★★ — 시험 100% 급
| | call by value (값에 의한 호출) | call by reference (참조에 의한 호출) |
|--|------------------------------|-----------------------------------|
| 넘기는 것 | 값의 **복사본** | 변수의 **주소** |
| 원본 변경 | ❌ 안 됨 | ✅ 됨 |
| 예제 | [call_by_value.c](src/09_포인터/call_by_value.c) | [call_by_ref.c](src/09_포인터/call_by_ref.c) |

```c
void modify(int value){ value = 99; }   // 복사본만 바뀜 → 원본 그대로 1
void modify(int *ptr){ *ptr = 99; }      // 주소로 접근 → 원본이 99로 바뀜
```

### swap 예제 — 단골 비교문제
- [swap1.c](src/09_포인터/swap1.c) : `swap(int x,int y)` → 복사본만 교환, **원본 안 바뀜 (실패)**
- [swap2.c](src/09_포인터/swap2.c) ★ : `swap(int *px,int *py)` + `swap(&a,&b)` → 주소로 교환, **원본 바뀜 (성공)**
```c
void swap(int *px, int *py){
    int tmp = *px;  *px = *py;  *py = tmp;
}
swap(&a, &b);   // 호출 시 주소를 넘김
```

## 3. 배열과 포인터 ★★
- **배열 이름 = 첫 번째 원소의 주소** ( `a == &a[0]` )
  - [p_array1.c](src/09_포인터/p_array1.c) : `a` 와 `&a[0]` 가 같은 주소 출력
- 포인터로 배열 접근 가능: `p = a;` 이후 `p[0], p[1]` == `a[0], a[1]`
  - [p_array2.c](src/09_포인터/p_array2.c)
- **포인터 산술**: `p+1` 은 1바이트가 아니라 **자료형 크기만큼** 증가
  - [pointer_arith1.c](src/09_포인터/pointer_arith1.c) : `char*`(+1), `int*`(+4), `double*`(+8) 증가폭 비교 ← 출력 추적 문제 나옴
- 배열을 함수 인자로: 주소가 넘어가므로 함수 안에서 **원본 배열 수정 가능**
  - [p_func.c](src/09_포인터/p_func.c) : `get_array_avg(int values[], int n)` — 배열 평균
  - "배열을 이용한 호출 (1)(2)(3)" 추가 예제: [src/09_포인터/배열을_이용한_호출_1.c](src/09_포인터/배열을_이용한_호출_1.c), [_2](src/09_포인터/배열을_이용한_호출_2.c), [_3](src/09_포인터/배열을_이용한_호출_3.c)

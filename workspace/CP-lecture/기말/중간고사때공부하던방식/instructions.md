"중간고사때 쓰던 instruction 임. 이제 이거 참고해서 기말고사 내용으로 만들어야만 해."

너는 C프로그래밍 과목 중간고사 출제자다.

다음 시험 정보를 기준으로 중간고사 대비 모의고사를 만들어라.

시험 정보:
- 범위: C언어 1장 ~ 7장
- 배점: 총 30점 만점
- 문제 수: 반드시 8문제
- 형식: 필답 고사
- 채점 기준: 정답이 아니어도 설명, 접근 과정, 코드 구조가 맞으면 부분 점수를 줄 수 있도록 구성
- 난이도: 실제 중간고사 대비용. 너무 쉽지만은 않게, 개념 이해와 코드 작성 능력을 함께 확인할 것

출제 범위와 반영할 내용:
1장:
- 프로그램, 소스 코드, 컴파일러, 실행 파일의 개념
- 알고리즘의 의미
- C언어 특징
- 소스 작성 → 컴파일 → 실행 → 디버깅 흐름
- 순서도 기호의 의미

2장:
- `#include <stdio.h>`, `main`, `printf`, `scanf`, `return 0`
- 기본 입출력 코드 작성
- `scanf`에서 `&` 사용
- 문법 오류 찾기와 수정

3장:
- 식별자 규칙
- 정수형, 실수형, 문자형, 문자열
- `int`, `short`, `unsigned short`, `float`, `double`
- 출력 형식 지정자 `%d`, `%f`, `%lf`, `%u` 등
- 상수, 기호 상수 `#define`, `const`
- 16진수 표현 `0xF`, `0x10`
- 형변환과 연쇄 대입 예: `y = x = 2.5`
- 이스케이프 문자

4장:
- 산술 연산자, 관계 연산자, 논리 연산자
- 증감 연산자 `x++`, `++x`
- 연산자 우선순위
- 정수 나눗셈과 실수 나눗셈
- 대입 연산자와 비교 연산자 구분

5장:
- `if`, `if-else`, 중첩 조건문
- 조건식의 참/거짓 판단
- `if (x = 0)` 같은 실수
- 조건문 뒤 세미콜론 오류
- 삼항 연산자
- `switch`, `case`, `default`, `break`
- `break`가 없을 때 fall-through 현상

6장:
- `for`, `while`, `do-while`
- 반복문의 초기식, 조건식, 증감식
- 반복 횟수 계산
- 중첩 반복문
- 별 찍기 또는 숫자 출력
- `break`, `continue`
- `short` 자료형의 범위와 오버플로우 감각

7장:
- 일차원 배열 선언, 초기화, 접근
- 배열 인덱스는 0부터 시작
- 배열 합계, 평균, 최댓값/최솟값 구하기
- 이차원 배열 선언과 접근
- 행렬 덧셈 구현
- 버블 정렬 구현과 동작 과정
- 배열을 이용한 코드 추적 문제

문제 구성 지침:
- 반드시 총 8문제로 출제한다.
- 총점은 반드시 30점이 되게 배점한다.
- 개념 문제와 구현 문제를 적절히 섞는다.
- 단순 암기만 묻지 말고, 코드 실행 결과 예측, 오류 수정, 짧은 설명, 직접 구현 문제를 골고루 포함한다.
- 7장 배열 문제는 반드시 포함한다.
- 버블 정렬 문제도 반드시 포함한다.
- 이차원 배열 또는 행렬 덧셈 문제도 반드시 포함한다.
- 조건문과 반복문은 각각 최소 1문제 이상 포함한다.
- 코드 작성 문제는 너무 긴 프로그램이 아니라 시험장에서 손으로 쓸 수 있는 수준으로 낸다.
- 포인터, 함수, 구조체처럼 1~7장 범위를 벗어나는 내용은 출제하지 않는다.
- C++ 문법보다 C언어 문법을 기준으로 출제한다.

권장 문제 배치:
1번. 1장 기본 개념 단답/서술 문제 - 3점
2번. 2장 기본 입출력 코드 오류 수정 문제 - 3점
3번. 3장 자료형, 형식 지정자, 형변환, 상수 관련 코드 실행 결과 예측 문제 - 4점
4번. 4장 연산자 우선순위, 증감 연산자, 정수 나눗셈 관련 코드 추적 문제 - 4점
5번. 5장 조건문 또는 switch문 코드 실행 결과와 이유 설명 문제 - 4점
6번. 6장 반복문 코드 작성 또는 실행 결과 예측 문제 - 4점
7번. 7장 일차원 배열을 이용한 합계/평균/최댓값/최솟값 또는 배열 값 변경 문제 - 4점
8번. 7장 종합 구현 문제: 이차원 배열 행렬 덧셈 또는 버블 정렬 구현/추적 문제 - 4점

출력 형식:
1. 먼저 “C프로그래밍 중간고사 대비 모의고사”라는 제목을 쓴다.
2. 시험 정보 요약을 짧게 적는다.
3. 8문제를 번호순으로 제시한다.
4. 각 문제 옆에 배점을 표시한다.
5. 각 문제는 실제 시험지처럼 바로 풀 수 있게 명확히 작성한다.
6. 문제 아래에 바로 정답을 쓰지 않는다.
7. 문제를 모두 낸 뒤, 별도 섹션으로 “정답 및 해설”을 작성한다.
8. 해설에는 부분 점수 기준도 함께 적는다.
9. 코드 문제의 정답은 C언어 코드로 작성한다.
10. 코드 실행 결과 문제는 출력 결과와 그 이유를 설명한다.

채점 기준 작성 방식:
- 각 문제마다 만점 기준을 적는다.
- 부분 점수를 어떻게 줄 수 있는지 구체적으로 적는다.
- 예를 들어 코드 구현 문제는 다음처럼 나눈다:
  - 변수 선언이 적절함
  - 입력/출력 처리가 맞음
  - 조건문 또는 반복문 구조가 맞음
  - 배열 인덱스 사용이 맞음
  - 최종 결과가 정확함
- 설명형 문제는 핵심 키워드가 들어가면 부분 점수를 줄 수 있게 한다.

출제 스타일:
- 교수님 필답 고사처럼 간결하고 직접적인 문장으로 출제한다.
- 학생이 손으로 답안을 작성할 수 있는 분량으로 낸다.
- 너무 장황한 시나리오 문제는 피한다.
- 구현 문제는 `#include <stdio.h>`와 `int main(void)`를 사용하는 기본 형태를 권장한다.
- 배열 문제에서는 크기가 너무 큰 배열을 쓰지 말고 3~5개 또는 2x2, 3x3 정도로 제한한다.

반드시 포함해야 하는 대표 소재:
- `scanf("%d", &x);`에서 `&`의 필요성
- `int x; float y; y = x = 2.5;`의 실행 결과
- `0x10`의 10진수 값
- `if (x = 10)`과 `if (x == 10)`의 차이
- `switch`에서 `break`가 없을 때의 동작
- `for` 반복문의 실행 횟수
- 배열 인덱스가 0부터 시작한다는 점
- 버블 정렬에서 인접한 두 값을 비교하고 교환하는 과정
- 이차원 배열을 이용한 행렬 덧셈

최종적으로 실제 학생이 30~50분 정도 풀 수 있는 8문제짜리 모의고사를 생성하라.

### 7번. 일차원 배열 코드 추적 [4점]

```c
#include <stdio.h>

int main(void)
{
    int arr[5] = {4, 1, 7, 3, 2};
    int i;
    int sum = 0;
    int max = arr[0];

    for (i = 0; i < 5; i++) {
        sum += arr[i];

            max = arr[i];

    printf("sum=%d\n", sum);
    printf("max=%d\n", max);
    printf("arr[1]=%d\n", arr[1]);

    return 0;
}
```

### 2번 정답 및 해설 [3점]

정답 예시:

```c
#include <stdio.h>

int main(void)
{
    int x;
    printf("정수 입력: ");
    scanf("%d", &x);
    printf("입력값은 %d입니다.\n", x);
    return 0;
}
```

해설:

- `#include <stdio.h>`에서 `#`가 필요하다.
- `int x;`처럼 선언문 끝에는 세미콜론이 필요하다.
- `scanf("%d", &x);`에서 `&x`는 변수 `x`의 주소를 의미한다. `scanf`는 입력값을 해당 주소에 저장해야 하므로 `&`가 필요하다.
- `printf` 문장 끝에도 세미콜론이 필요하다.

부분 점수 기준:

- `#include <stdio.h>` 수정: 0.5점
- 변수 선언 세미콜론 수정: 0.5점
- `scanf`에서 `&x` 사용: 1점
- `printf` 세미콜론 및 전체 코드 구조 수정: 0.5점
- `&`의 필요성을 주소와 입력 저장 관점에서 설명: 0.5점

### 3번 정답 및 해설 [4점]

출력 결과:

```text
A=16
x=2
y=2.0
```

부분 점수 기준:

- `0x10`의 값 16을 정확히 제시: 0.8점
- `x`가 2가 되는 이유 설명: 1점
- `y`가 2.0이 되는 이유 설명: 1점
- `unsigned short`와 `%u` 출력 결과 제시: 0.8점
- 전체 출력 형식을 줄 단위로 정확히 작성: 0.4점

### 4번 정답 및 해설 [4점]

출력 결과:

```text
a=6
b=3
c=11
d=3
e=3.5
```

해설:

- 처음 `a = 5`, `b = 2`이다.
- `a++`는 현재 값 5를 식에 사용한 뒤 `a`를 6으로 증가시킨다.
- `++b`는 먼저 `b`를 3으로 증가시킨 뒤 식에 사용한다.
- 곱셈이 덧셈보다 우선이므로 `++b * 2`는 `3 * 2 = 6`이다.
- 따라서 `c = 5 + 6 = 11`이다.
- `7 / 2`는 정수 나눗셈이므로 몫인 3이 된다.
- `7 / 2.0`은 실수 나눗셈이므로 3.5가 된다.

부분 점수 기준:

- 후위 증가 `a++` 처리 설명 및 `a=6` 제시: 0.8점
- 전위 증가 `++b` 처리 설명 및 `b=3` 제시: 0.8점
- 연산자 우선순위를 반영하여 `c=11` 계산: 1점
- 정수 나눗셈 `7 / 2` 결과 설명: 0.7점
- 실수 나눗셈 `7 / 2.0` 결과 설명: 0.7점

### 5번 정답 및 해설 [4점]

출력 결과:

```text
A
two
three
```

해설:

- `if (x = 10)`은 비교가 아니라 대입이다. `x`에 10이 저장되고, 조건식의 값도 10이 된다.
- C언어에서 0은 거짓, 0이 아닌 값은 참이므로 `A`가 출력된다.
- `if (x == 10)`은 `x`가 10인지 비교하는 조건식이다.
- `switch (menu)`에서 `menu`가 2이므로 `case 2`부터 실행된다.
- `case 2` 뒤에 `break`가 없으므로 `case 3`까지 이어서 실행된다. 이를 fall-through라고 한다.
- `case 3`에는 `break`가 있으므로 `default`는 실행되지 않는다.

부분 점수 기준:

- `if (x = 10)`의 대입 동작 설명: 1점
- 조건식 참/거짓 판단으로 `A` 출력 제시: 0.7점
- `==`와 `=`의 차이 설명: 0.7점
- `switch`에서 `case 2`부터 실행됨을 설명: 0.6점
- `break`가 없어 `two`, `three`가 출력됨을 설명: 1점

### 6번 정답 및 해설 [4점]

정답 예시:

```c
#include <stdio.h>

int main(void)
{
    int n;
    int i;
    int sum = 0;

    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        if (i % 3 == 0)
            continue;
        printf("%d ", i);
        sum += i;
    }

    printf("\nsum=%d\n", sum);

    return 0;
}
```

해설:

- `for (i = 1; i <= n; i++)`이므로 반복 조건 검사는 `i`가 1부터 `n`까지일 때 참이 된다.
- 반복문의 몸체는 총 `n`번 실행된다.
- `i % 3 == 0`이면 3의 배수이므로 `continue`를 만나 출력과 합산을 건너뛴다.

부분 점수 기준:

- `n`, `i`, `sum` 등 필요한 변수 선언: 0.5점
- `scanf`로 `n` 입력 처리: 0.5점
- `for` 반복문 범위를 `1`부터 `n`까지 적절히 작성: 1점
- 3의 배수 판별 조건 작성: 0.7점
- `continue` 사용 위치가 적절함: 0.6점
- 출력과 합계 계산이 정확함: 0.5점
- 반복 횟수가 `n`번임을 설명: 0.2점

### 8번 정답 및 해설 [4점]

정답 예시:

```c
#include <stdio.h>

int main(void)
{
    int A[2][2], B[2][2], C[2][2];
    int list[4];
    int i, j;
    int k = 0;
    int temp;

    for (i = 0; i < 2; i++) {
        for (j = 0; j < 2; j++) {
            scanf("%d", &A[i][j]);
        }
    }

    for (i = 0; i < 2; i++) {
        for (j = 0; j < 2; j++) {
            scanf("%d", &B[i][j]);
        }
    }

    for (i = 0; i < 2; i++) {
        for (j = 0; j < 2; j++) {
            C[i][j] = A[i][j] + B[i][j];
            list[k] = C[i][j];
            k++;
        }
    }

    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3 - i; j++) {
            if (list[j] > list[j + 1]) {
                temp = list[j];
                list[j] = list[j + 1];
                list[j + 1] = temp;
            }
        }
    }

    for (i = 0; i < 4; i++) {
        printf("%d ", list[i]);
    }

    return 0;
}
```

해설:

- `A`, `B`, `C`는 모두 2행 2열 배열이다.
- 같은 위치의 원소끼리 더해 `C[i][j] = A[i][j] + B[i][j]`로 저장한다.
- `C`의 네 원소를 `list[0]`부터 `list[3]`까지 차례대로 저장한다.
- 버블 정렬은 인접한 두 원소 `list[j]`, `list[j + 1]`을 비교하여 앞의 값이 더 크면 교환한다.
- 원소가 4개이므로 바깥 반복은 최대 3회면 충분하다.

부분 점수 기준:

- 2x2 배열 `A`, `B`, `C`와 일차원 배열 `list[4]` 선언: 0.6점
- `A`, `B` 입력을 이중 반복문으로 처리: 0.6점
- 행렬 덧셈 `C[i][j] = A[i][j] + B[i][j]` 구현: 0.8점
- `C`의 값을 `list`에 올바른 인덱스로 저장: 0.6점
- 버블 정렬의 반복 구조 작성: 0.7점
- 인접 원소 비교와 교환 구현: 0.5점

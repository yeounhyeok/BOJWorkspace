## 핵심 오답 정리

### 3번

정답은 다음과 같다.

```text
A=16
x=2
y=2.0
z=65535
```

`y = x = 2.5;`는 `x = 2.5`가 먼저 실행된다. `x`는 `int`라서 `2`가 저장되고, 그 결과가 `y`에 들어가므로 `y`는 `2.0`이 된다.

### 5번

정답 출력은 다음과 같다.

```text
A
two
three
```

`switch(menu)`에서 `menu`가 2이므로 `case 2`부터 실행된다. `case 1`은 실행되지 않는다. `case 2`에 `break`가 없어서 `case 3`까지 이어진다.

### 6번

권장 형태는 다음과 같다.

```c
for (i = 1; i <= n; i++) {
    if (i % 3 == 0)
        continue;
    printf("%d ", i);
    sum += i;
}
```

반복문 몸체는 `i=1`부터 `i=n`까지 총 `n`번 실행된다. 실제 출력 및 합산되는 수의 개수는 3의 배수를 제외하므로 `n - n / 3`개이다.

### 8번

행렬 덧셈 후 list 저장은 다음처럼 쓰는 것이 안전하다.

```c
C[i][j] = A[i][j] + B[i][j];
list[k] = C[i][j];
k++;
```

버블 정렬 비교와 교환은 안쪽 반복 변수 `j`를 기준으로 해야 한다.

```c
for (i = 0; i < 3; i++) {
    for (j = 0; j < 3 - i; j++) {
        if (list[j] > list[j + 1]) {
            temp = list[j];
            list[j] = list[j + 1];
            list[j + 1] = temp;
        }
    }
}
```

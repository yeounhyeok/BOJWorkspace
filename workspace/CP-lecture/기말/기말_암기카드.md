## 🔴 1. 내가 틀렸던 것 (제일 먼저!)

1. **swap/회전 = 덮어쓸 값을 먼저 백업, 임시변수는 `int`(값)**
   - `int tmp = *a;` ⭕ / `int *tmp;`(포인터) ❌ ← 초기화 안 된 포인터 역참조 = 크래시
   - "누가 누구 값을 받는지" 화살표로 그려라. `a←c, b←a, c←b` 면 **마지막(c) 먼저 백업**.
2. **`%.1f`는 반올림 (버림 아님)** → `81.666` → `81.7` (`81.6` ❌)
3. **C 문자열은 `=`, `==`, `+` 안 됨**
   - 복사 `strcpy`, 비교 `strcmp(...)==0`, 붙이기 `strcat`. `char s[]="..."`는 **선언할 때만** 가능.
4. **버블정렬 안쪽 루프**: `for(j=0; j<n-1-i; j++)` 비교는 **`a[j]` vs `a[j+1]`** (`i` 아님!)
5. **`char s[]` 수정 O / `char *p="..."` 수정 X**(리터럴, `p[0]='x'`면 크래시)

## 📌 2. 문자열 함수 인자 (string.h) — 꼭 외우기

| 함수 | 인자 (순서 주의) | 반환 |
|------|------------------|------|
| `strlen(s)` | 문자열 | 길이(**`'\0'` 제외**) |
| `strcpy(dst, src)` | **목적지 먼저, 원본 나중** (dst ← src) | dst |
| `strcat(dst, src)` | dst 끝에 src 붙임 | dst |
| `strcmp(s1, s2)` | 두 문자열 | **같으면 0**, 다르면 ± |
| `atoi(s)` / `atof(s)` | 문자열 | int / double |

입력:
- `scanf("%s", s)` → **`&` 안 붙임** (배열 이름이 이미 주소). 공백 못 받음.
- `gets_s(s, 크기)` → 공백 포함 한 줄.
- **`& 언제?`** : `scanf("%d", &x)` 정수/실수엔 `&` 필요 / `%s`(문자배열)엔 불필요.

## 🎯 3. 포인터 (킬러 대비, 최우선)

```c
&x        // x의 주소
*p        // p가 가리키는 값
int *p = &x;  *p = 10;   // x가 10으로 바뀜
```

**swap (call by reference) — 통째로 외우기:**
```c
void swap(int *px, int *py){ int t=*px; *px=*py; *py=t; }
swap(&a, &b);   // 호출은 주소로!
```
- 값으로 받으면(`int x`) **복사본만 바뀜 → 원본 그대로**.
- **배열 이름 = 첫 원소 주소** (`a == &a[0]`), 배열을 함수에 넘기면 **원본이 바뀜**.
- `*(p+i) == p[i]` / **`*p+1`(값+1) ≠ `*(p+1)`(다음 원소)**
- `*p++` : 지금 값 쓰고 → p 이동 / `*++p` : p 먼저 이동 → 값
- `포인터 - 포인터` = **인덱스 차이** (`m - a` = 몇 번째)
- 구조체 포인터: **`p->멤버` == `(*p).멤버`**
- 결과 2개 돌려주기: `&out` 넘기고 함수 안에서 `*out = 값;`

## ⚡ 4. 자주 나오는 함수 시그니처

```c
// 동적 메모리 (stdlib.h)
int *p = (int *)malloc(n * sizeof(int));  // 형변환+개수*sizeof
if (p == NULL) { ... }                    // 실패 검사
free(p);                                  // 해제

// 파일 (stdio.h)  — 3단계: 열고→NULL검사→닫기
FILE *fp = fopen("name", "모드");   // 실패 시 NULL
fprintf(fp, "%d", x);  fscanf(fp, "%d", &x);
fgets(buf, 크기, fp);  fputs(str, fp);
fread (ptr, 원소크기, 개수, fp);    // 이진
fwrite(ptr, 원소크기, 개수, fp);
fseek(fp, 오프셋, SEEK_SET/CUR/END);
fclose(fp);
```
**fopen 모드**: `r`읽기(없으면 NULL) · `w`쓰기(**기존 삭제·덮어쓰기**) · `a`추가(**뒤에 이어쓰기**) · `b`이진(`rb`/`wb`)

### 📂 파일 함수 인자 순서 (fp 위치가 함정!)

| 함수 | 인자 순서 | fp 위치 | 기능 |
|------|-----------|:--:|------|
| `fopen(이름, 모드)` | name, mode | — | 열기 (실패 NULL) |
| `fclose(fp)` | fp | — | 닫기 |
| `fprintf(fp, "fmt", 값)` | **fp 먼저** | 앞 | 서식 쓰기 |
| `fscanf(fp, "fmt", &x)` | **fp 먼저** | 앞 | 서식 읽기 |
| `fputs(str, fp)` | 문자열, fp | **뒤** | 한 줄(문자열) 쓰기 |
| `fgets(buf, 크기, fp)` | 버퍼, 크기, fp | **뒤** | 한 줄 읽기(크기 필수) |
| `fputc(ch, fp)` | 문자, fp | **뒤** | 문자 1개 쓰기 |
| `fgetc(fp)` | fp | — | 문자 1개 읽기(**int** 반환) |
| `fwrite(ptr, 크기, 개수, fp)` | 주소,크기,개수,fp | **맨끝** | 이진 쓰기 |
| `fread(ptr, 크기, 개수, fp)` | 주소,크기,개수,fp | **맨끝** | 이진 읽기 |
| `fseek(fp, 오프셋, 기준)` | **fp 먼저** | 앞 | 위치 이동(SEEK_SET/CUR/END) |
| `ftell(fp)` | fp | — | **현재 위치(바이트)** 반환(`long`) |
| `rewind(fp)` | fp | — | 맨 처음으로 (= `fseek(fp,0,SEEK_SET)`) |

**★ 외우는 법**: `f`+`printf/scanf/seek` = **fp가 맨 앞** / `puts/gets/putc` = **fp가 뒤** / `fread/fwrite` = **fp가 맨끝**
(`fgetc`는 fp 하나, **반환을 `int`로** 받기 — EOF 때문)

## 5. 함수 / static / 구조체 한 줄 정리

- **함수 원형**은 main 위에 선언. `void`는 반환값 없음.
- **지역**(매번 새로) / **전역**(어디서나) / **static**(값 유지, 1·2·3 누적, 초기화 1번)
- **재귀**: 반드시 **종료 조건**. `factorial(n)= n*factorial(n-1)`, `n<=1`이면 1.
- 구조체: 변수는 **`.`**, 포인터는 **`->`** / 배열 `list[i].멤버`
- `typedef` 별칭 / `union` 메모리 공유 / `enum` 0부터 자동 증가

## 6. 전처리 (가볍게, 1문제)

- `#define SQUARE(x) ((x)*(x))` → **괄호 필수!** 없으면 `SQUARE(2+3)` = `2+3*2+3 = 11`(틀림), 있으면 `25`
- `#define` = **컴파일 전 단순 텍스트 치환**
- `#ifdef`/`#if`/`#elif`/`#else`/`#endif` → 조건에 맞는 한 가지만 컴파일

# 🔑 연산자 우선순위 — 포인터 `*` vs `++` 싹 정리

> ※ gcc로 직접 실행해서 검증한 결과. 시험 단골 = `*p++`, `*++p`, `(*p)++`, `*p+1`.

## 1. 우선순위 표 (위 = 높음)

| 순위 | 연산자 | 결합방향 |
|:--:|---|:--:|
| 1 (최고) | **후위** `++` `--`, `()` 함수호출, `[]` 배열, `.` , `->` | 왼→오 |
| 2 | **전위** `++` `--`, `!`, `~`, **`*`(역참조)**, **`&`(주소)**, `sizeof`, `(형변환)`, 단항 `-` | **오→왼** |
| 3 | `*` `/` `%` (곱셈·나눗셈) | 왼→오 |
| 4 | `+` `-` (덧셈·뺄셈) | 왼→오 |
| 5 | `<` `<=` `>` `>=` | 왼→오 |
| 6 | `==` `!=` | 왼→오 |
| 7~ | `&` → `^` → `\|` → `&&` → `\|\|` | 왼→오 |
| 8 | `? :` (삼항) | 오→왼 |
| 9 | `=` `+=` `-=` ... (대입) | **오→왼** |
| 10 (최저) | `,` (콤마) | 왼→오 |

### ★ 딱 3개만 기억하면 포인터 문제 다 풀림
1. **후위 `++`(`p++`) > `*`(역참조)** → `*p++` 는 `*(p++)`
2. **전위 `++`(`++p`) 와 `*` 는 같은 단항 레벨, 오→왼** → `*++p` 는 `*(++p)`
3. **`*`(역참조) > `+`(덧셈)** → `*p + 1` 은 `(*p) + 1`

## 2. 포인터 조합 완전 해부 (검증된 결과)

`int a[5] = {10,20,30,40,50}; int *p = a;` 기준

| 식 | 묶음 | 동작 | 반환값 | p / 배열 변화 |
|---|---|---|:--:|---|
| `*p++` | `*(p++)` | 지금 값 쓰고 → **p 이동** | **10** | p가 a[1]로 이동 |
| `*++p` | `*(++p)` | **p 먼저 이동** → 값 | **20** | p가 a[1]로 이동 |
| `(*p)++` | 괄호로 값 먼저 | **가리킨 값**을 증가(후위) | **10** | a[0]=11, p 제자리 |
| `++*p` | `++(*p)` | **가리킨 값** 먼저 증가 | **11** | a[0]=11, p 제자리 |
| `*p + 1` | `(*p)+1` | 값 꺼내 +1 (계산만) | **11** | 아무것도 안 바뀜 |
| `*(p+1)` | 괄호로 주소 먼저 | **다음 원소**의 값 | **20** | 안 바뀜 |

핵심 대비:
- **`*p++` vs `*++p`** : 후위는 "쓰고 이동", 전위는 "이동하고 씀" → 반환값 `10` vs `20`
- **`*p+1` vs `*(p+1)`** : 앞은 "값+1(=11)", 뒤는 "다음 원소(=20)" — 완전 다름!
- **`*p++` vs `(*p)++`** : 앞은 **포인터**가 이동, 뒤는 **가리킨 값**이 증가 (괄호 차이)

## 3. 자주 틀리는 함정

- **`*p.x` ❌ → `(*p).x` 또는 `p->x` ⭕**
  `.`(후위)가 `*`(단항)보다 높아서 `*p.x` 는 `*(p.x)`로 해석됨(보통 컴파일 에러). 구조체 포인터 멤버는 꼭 `p->x` 또는 `(*p).x`.
- **`&a[0]` = `&(a[0])`** : `[]`가 `&`보다 높음 → "0번 원소의 주소" (의도대로 OK).
- **역참조 `*` ≠ 곱셈 `*`** : `*p`(단항, 높음) vs `a * b`(곱셈, 낮음)는 다른 연산자. 헷갈리지 말 것.
- **곱셈이 덧셈보다 먼저** : `2 + 3 * 2 = 8`, 매크로 `SQUARE(2+3)`가 `2+3*2+3=11`로 깨지는 이유.
- **대입은 오→왼** : `y = x = 2.5;` → `x=2.5` 먼저(`x`가 int면 2), 그 값이 `y`로.
- **확실하지 않으면 그냥 괄호** 쳐라. 시험에선 `(*p)`, `*(p+1)`처럼 괄호로 의도 표현하면 안전.

## 4. 미니 연습 (답은 위 표로 확인)

```c
int a[4] = {1, 2, 3, 4};
int *p = a;
printf("%d\n", *p++);   // 1  (그 후 p→a[1])
printf("%d\n", *p);     // 2
printf("%d\n", *p + 1); // 3   (값 2 +1)
printf("%d\n", *(p+1)); // 3   (다음 원소 a[2])  ← *p+1과 우연히 같지만 의미 다름!
```
> 마지막 두 줄: `*p+1`은 "현재값(2)+1=3", `*(p+1)`은 "다음 원소 a[2]=3". 값은 같아도 **이유가 완전히 다름** — 이런 걸 노린다.

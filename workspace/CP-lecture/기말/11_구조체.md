## 1. 구조체란
- 서로 다른 자료형을 **하나로 묶는** 사용자 정의 자료형. (배열=같은 타입만, 구조체=다른 타입 묶음)
```c
struct student {     // 구조체 정의 (멤버: 다른 타입 묶음)
    int number;
    char name[20];
    double grade;
};
struct student s = { 20070001, "홍길동", 4.3 };  // 변수 선언 + 초기화
printf("%d %s %.1f", s.number, s.name, s.grade);  // 멤버 접근은 점(.)
```
- [student1.c](src/11_구조체/student1.c) : 기본 선언/초기화/출력
- [struct_init.c](src/11_구조체/struct_init.c) : 초기화 방법 — `{1,2}` 순서대로 / `{.y=2,.x=1}` 지정 초기화
- [point.c](src/11_구조체/point.c) : 점 두 개 거리 계산 (멤버 활용)

## 2. 멤버 접근: `.` vs `->` ★★ (시험 단골)
| 상황 | 연산자 | 예 |
|------|--------|----|
| 구조체 **변수** | `.` (점) | `s.number` |
| 구조체 **포인터** | `->` (화살표) | `p->number` (== `(*p).number`) |

- [pointer_to_st.c](src/11_구조체/pointer_to_st.c) ★ : `struct student *p = &s;` 후 `p->number`, `p->name`
  - `p->number` 와 `(*p).number` 는 **완전히 같은 뜻**.

## 4. 구조체와 함수
- 구조체를 **인자/반환값**으로 통째로 주고받기 가능 (값 복사)
- [vector.c](src/11_구조체/vector.c) : `struct vector get_vector_sum(struct vector a, struct vector b)` — 구조체 반환
- [typedef.c](src/11_구조체/typedef.c) : `typedef struct point {...} POINT;` 로 별칭 만들어 `POINT p;` 처럼 짧게. 함수 `POINT translate(POINT p, POINT delta)`
  - ⚠️ 구조체를 통째로 넘기면 **복사**됨(값 호출). 큰 구조체는 포인터(`*`)로 넘기는 게 효율적.

## 5. typedef / union / enum
| 키워드 | 의미 | 예제 |
|--------|------|------|
| `typedef` | 자료형에 **별칭** 부여 | [typedef.c](src/11_구조체/typedef.c) |
| `union` | 멤버들이 **같은 메모리 공유** (한 번에 하나만 유효) | [union.c](src/11_구조체/union.c) |
| `enum` | 정수 상수에 이름 (MON=0, TUE=1...) | [enum1.c](src/11_구조체/enum1.c) |

- **union**: `union example { int i; char c; };` → `i` 와 `c` 가 메모리를 겹쳐 씀. `data.c='A'` 넣으면 `data.i` 도 영향받음 (구조체와의 결정적 차이!).
- **enum**: `enum days { MON, TUE, ... SUN };` → MON=0부터 자동 증가. `for(d=MON; d<=SUN; d++)` 가능.

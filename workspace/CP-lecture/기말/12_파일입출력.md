# 12장 파일 입출력 (File I/O)

> 예제 코드: [src/12_파일입출력/](src/12_파일입출력/)

## 1. 파일 처리 3단계 ★★
```c
FILE *fp = fopen("파일명", "모드");   // ① 열기
if (fp == NULL) { ... exit(1); }       //   반드시 NULL 검사!
fprintf(fp, ...); / fscanf(fp, ...);   // ② 읽기/쓰기
fclose(fp);                            // ③ 닫기
```
- **`fp == NULL` 검사 빼면 감점/오류** — 거의 모든 예제가 검사함. → [file_open.c](src/12_파일입출력/file_open.c)

## 2. fopen 모드 ★★★ (시험 단골 표)
| 모드 | 의미 | 파일 없으면 | 기존 내용 |
|------|------|-------------|-----------|
| `"r"` | 읽기 | 오류(NULL) | 유지 |
| `"w"` | 쓰기 | 새로 생성 | **싹 지움(덮어쓰기)** |
| `"a"` | 추가 | 새로 생성 | 뒤에 이어쓰기 |
| `"r+/w+/a+"` | 읽기+쓰기 | 모드별 | |
| `"rb"/"wb"` | **이진(binary)** 읽기/쓰기 | | |

- `"w"` 와 `"a"` 차이 꼭 기억: w는 덮어쓰기, a는 이어쓰기 → [fprintf.c](src/12_파일입출력/fprintf.c) (`"a"` 로 매출 누적)
- `b` 가 붙으면 텍스트 변환 없이 **바이트 그대로** (이미지/raw 등)

## 3. 텍스트 파일 입출력
| 단위 | 출력 | 입력 |
|------|------|------|
| 서식 | `fprintf` | `fscanf` |
| 문자 | `fputc` | `fgetc` |
| 줄/문자열 | `fputs` | `fgets` |

- [fputs.c](src/12_파일입출력/fputs.c) / [fgetc.c](src/12_파일입출력/fgetc.c) / [fgets.c](src/12_파일입출력/fgets.c)
- [score3.c](src/12_파일입출력/score3.c) : 성적을 파일에 `fprintf` 로 쓰고 다시 읽기
- [fcopy1.c](src/12_파일입출력/fcopy1.c) : 파일 복사 (한 문자씩 읽어 쓰기, EOF까지)

## 4. 이진 파일 입출력 (fread / fwrite)
```c
fwrite(buffer, sizeof(int), SIZE, fp);  // (주소, 한 원소 크기, 개수, 파일)
fread (buffer, sizeof(int), SIZE, fp);
```
- [binary1.c](src/12_파일입출력/binary1.c) : `int` 배열을 `"wb"` 로 통째로 저장
- [binary2.c](src/12_파일입출력/binary2.c) : `"rb"` 로 통째로 읽기
- 텍스트보다 빠르고 용량 작음, 사람이 직접 못 읽음.

## 5. 파일 위치 이동 fseek
```c
fseek(fp, offset, 기준);   // 기준: SEEK_SET(처음) SEEK_CUR(현재) SEEK_END(끝)
ftell(fp);                 // 현재 위치(바이트)
```
- [fseek1.c](src/12_파일입출력/fseek1.c) : `fseek(fp,0,SEEK_END)` + `ftell` 로 **파일 크기 구하기**
- [fseek2.c](src/12_파일입출력/fseek2.c) : 파일 내 특정 위치로 점프해서 읽기
- [imagedisp.c](src/12_파일입출력/imagedisp.c) : raw 이미지 파일 읽어 화면 출력 (windows.h, 참고용)

## 🎯 시험 포인트 요약
- **3단계: fopen → (NULL검사) → 입출력 → fclose**
- **fopen 모드표** (r/w/a/rb/wb, w는 덮어쓰기 vs a는 이어쓰기)
- 텍스트(fprintf/fscanf/fgets/fputs) vs 이진(fread/fwrite)
- fseek + ftell 로 파일 크기/위치

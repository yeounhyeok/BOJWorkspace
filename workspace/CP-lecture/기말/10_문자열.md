# 10장 문자열 (Strings)

> 예제 코드: [src/10_문자열/](src/10_문자열/)

## 1. 문자열의 정체 ★★
- C에는 문자열 타입이 따로 없음 → **`char` 배열 + 끝에 널 문자 `'\0'`**
- `"Seoul"` 은 메모리에 `S e o u l \0` (6칸) 저장됨. **널 문자가 문자열의 끝 표시.**
```c
char str1[6] = "Seoul";              // 자동으로 '\0' 포함
char str2[3] = {'i','s','\0'};       // 직접 널 넣기
char str3[]  = "...";                // 크기 생략 → 알아서 길이+1
```
- [string1.c](src/10_문자열/string1.c) : 여러 초기화 방법
- [string2.c](src/10_문자열/string2.c) : `str[0]='c';` 로 한 글자 수정 (komputer→computer)
- [string3.c](src/10_문자열/string3.c) : `while(str[i]!=0) i++;` 로 직접 길이 세기 (널 문자 만날 때까지)

## 2. char 배열 vs char 포인터 ★ (단골 함정)
| | `char s[] = "Hello";` | `char *p = "Hello";` |
|--|----------------------|----------------------|
| 저장 | 배열(스택)에 복사됨 | 문자열 상수 영역을 가리킴 |
| 내용 수정 | ✅ `s[0]='h'` 가능 | ❌ `p[0]='h'` → 실행 중단(크래시) |
| 가리키는 대상 변경 | ❌ | ✅ `p="Goodbye"` 가능 |

→ [char_ptr.c](src/10_문자열/char_ptr.c) (주석에 "이 문장 실행하면 작동 중지" 명시)

## 3. 문자열 입출력
| 함수 | 특징 |
|------|------|
| `scanf("%s", s)` | **공백 앞까지만** 입력받음 (한 단어) |
| `gets_s(s, 크기)` | **공백 포함** 한 줄 입력 |
| `getchar()/putchar()` | 문자 하나 입출력 (버퍼 사용, 엔터 필요) |
| `_getch()/_putch()` (conio.h) | 엔터 없이 즉시 문자 입력 |

- [stringio.c](src/10_문자열/stringio.c) (`scanf %s`) vs [stringio2.c](src/10_문자열/stringio2.c) (`gets_s`) → 공백 처리 차이
- [getchar.c](src/10_문자열/getchar.c) vs [_getchar.c](src/10_문자열/_getchar.c)
- ⚠️ `char ch` 보다 **`int ch`** 로 받는 게 정석 (EOF 처리). 예제 주석에도 "정수형에 주의".
- [password.c](src/10_문자열/password.c) : `_getch()` 로 비밀번호 입력(화면에 `*` 표시)

## 4. string.h 표준 함수 ★★
| 함수 | 기능 | 반환 |
|------|------|------|
| `strlen(s)` | 길이(널 제외) | 길이 |
| `strcpy(dst,src)` | 복사 | dst |
| `strcat(s1,s2)` | s1 뒤에 s2 이어붙임 | s1 |
| `strcmp(s1,s2)` | 사전순 비교 | 같으면 **0**, 다르면 ±값 |

- [strlen.c](src/10_문자열/strlen.c) · [strcpy.c](src/10_문자열/strcpy.c) · [strcat.c](src/10_문자열/strcat.c) · [strcmp.c](src/10_문자열/strcmp.c)
- ⚠️ `strcmp` 는 **같을 때 0** 반환 (참=1 아님!). `while(strcmp(a,b)!=0)` 패턴 → [calc_quiz.c](src/10_문자열/calc_quiz.c)
- 숫자 변환: `atoi("100")`→정수, `atof("36.5")`→실수 → [atoi.c](src/10_문자열/atoi.c)

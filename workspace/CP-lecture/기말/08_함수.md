## 2. 함수의 3요소 (★ 시험 단골)
```c
반환형 함수이름(매개변수목록);          // ① 함수 원형(prototype) — main 위에 선언
...
int main(void){  result = power(2,10); }  // ② 함수 호출(call)
...
반환형 함수이름(매개변수목록){ ... return 값; }  // ③ 함수 정의(definition)
```
- **함수 원형(prototype)** 을 main 위에 적는 이유: 컴파일러가 호출 전에 함수의 형태(반환형·인자)를 알아야 함. 안 적고 아래에 정의만 하면 오류/경고.
  → [prototype.c](src/08_함수/prototype.c), [temp.c](src/08_함수/temp.c)
- `return` : 값을 호출한 곳으로 돌려주고 함수 종료. 반환형이 `void` 면 돌려줄 값 없음.

## 3. 변수의 범위(scope)와 수명(lifetime) ★★ — 가장 잘 나옴
| 종류 | 선언 위치 | 범위 | 수명 | 초기값 |
|------|-----------|------|------|--------|
| **지역변수(local)** | 함수/블록 안 | 그 블록 안에서만 | 함수 끝나면 소멸 | 쓰레기값 |
| **전역변수(global)** | 함수 밖 | 모든 함수에서 접근 | 프로그램 끝까지 | 0 |
| **static 변수** | 함수 안 + `static` | 그 함수 안에서만 | **프로그램 끝까지 유지** | 0 |

- [local_var.c](src/08_함수/local_var.c) : `compute_sum()` 안의 `result` 는 지역변수
- [global_var.c](src/08_함수/global_var.c) : 전역변수 `global` 을 여러 함수가 공유
- [local_shadow.c](src/08_함수/local_shadow.c) : 전역 `sum=123` 과 지역 `sum=321` 이 같은 이름 → **지역변수가 우선(shadowing)**, 출력은 `321`
- [static.c](src/08_함수/static.c) ★ : 함수를 3번 호출하면
  - `auto_count` (일반 지역변수): 매번 0→1 → 출력 **1, 1, 1**
  - `static_count` : 값 유지 → 출력 **1, 2, 3**
  - **이거 출력값 맞히는 문제 자주 나옴!**

## 4. 재귀 함수(recursion) ★
- 함수가 자기 자신을 호출. **반드시 종료 조건(base case)** 이 있어야 무한루프 안 됨.
- [factorial.c](src/08_함수/factorial.c) :
```c
int factorial(int n){
    if (n <= 1) return 1;          // 종료 조건
    else return n * factorial(n-1); // 자기 자신 호출
}
```
  - `factorial(4)` → 4*factorial(3) → 4*3*factorial(2) → 4*3*2*factorial(1) → 4*3*2*1 = 24
  - **호출 과정(스택)을 손으로 그려보는 연습** 필수.

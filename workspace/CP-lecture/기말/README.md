## ⚠️ 시험 범위 정정
네가 말한 "**8장 함수 ~ 14장 동적할당**" 에서 장 번호가 살짝 어긋나 있어. 게시판 기준 실제 챕터는 이래:

| 장 | 제목 | 비고 |
|----|------|------|
| 8장 | 함수 | |
| 9장 | 포인터 | |
| 10장 | 문자열 | |
| 11장 | 구조체 | |
| 12장 | 파일 입출력 | |
| **13장** | **동적메모리(동적할당)** | ← 네가 말한 "동적할당"은 여기 |
| 14장 | 전처리와 매크로 / 분할 컴파일 | |

즉 **기말 범위 = 8~14장 전부**이고, "동적할당"은 13장, 14장은 "전처리/매크로"야.

## ✅ 시험 직전 통합 체크리스트
가장 자주 출제되는 핵심만 추렸어. 각 항목 체크하면서 보면 됨.

### 8장 함수
- [ ] 함수 **원형(prototype)** 을 main 위에 적는 이유 (선언 없이 호출 시 오류)
- [ ] `return` 의 의미, 반환형 `void` vs `int`/`double`
- [ ] **지역변수 vs 전역변수 vs static 변수** 의 수명/범위 차이 (static.c)
- [ ] **재귀 함수** 동작 과정 추적 (factorial.c — 호출 스택 손으로 그려보기)
- [ ] 변수 이름이 같을 때 **지역변수 우선(shadowing)** (local_shadow.c)

### 9장 포인터 ★
- [ ] `&`(주소 연산자) 와 `*`(간접참조 연산자) 구분
- [ ] **call by value vs call by reference** — swap 예제로 설명 가능해야 함
- [ ] **배열 이름 == 첫 원소의 주소** (`a == &a[0]`)
- [ ] 포인터 산술: `p+1` 은 타입 크기만큼 증가 (pointer_arith1.c)
- [ ] 배열을 함수 인자로 넘기면 주소가 넘어가서 **원본이 바뀜**

### 10장 문자열
- [ ] 문자열 = `char` 배열 + 끝에 **`'\0'`(널 문자)**
- [ ] `char s[]="..."`(수정O) vs `char *p="..."`(수정X) 차이 (char_ptr.c)
- [ ] `strlen / strcpy / strcat / strcmp` 동작과 반환값
- [ ] `scanf("%s")`(공백 못 받음) vs `gets_s`(공백 받음)

### 11장 구조체
- [ ] `struct` 선언, 멤버 접근 `.` vs 포인터 접근 `->`
- [ ] **구조체 배열**, 구조체를 함수 인자/반환값으로 사용
- [ ] `typedef` 로 별칭 만들기 / `union` / `enum`

### 12장 파일 입출력
- [ ] `fopen` 모드: **r, w, a, rb, wb** 의미 (특히 텍스트 vs 이진 `b`)
- [ ] **반드시 `fp==NULL` 검사** 후 `fclose`
- [ ] 텍스트: `fprintf/fscanf/fgets/fputs`, 이진: `fread/fwrite`
- [ ] `fseek` 으로 파일 위치 이동

### 13장 동적메모리 ★
- [ ] `malloc(개수 * sizeof(자료형))` + **형변환** + **NULL 검사** + **free**
- [ ] 동적 배열 / 동적 구조체 할당 패턴
- [ ] 정적 배열과의 차이 (실행 중 크기 결정 가능)

### 14장 전처리/매크로
- [ ] `#define` 단순 매크로 vs **함수형 매크로** (괄호 꼭 씌우는 이유!)
- [ ] `#ifdef / #else / #endif` 조건부 컴파일
- [ ] 전처리는 **컴파일 전 단순 텍스트 치환**

## ℹ️ 크롤링 메모
- 게시판은 EUC-KR 인코딩이라 UTF-8 변환해서 저장함.
- 코드는 게시글의 ColorScripter 블록에서 추출 → 깔끔한 `.c` 로 복원.

## 문제

### 1번. 종합 - 포인터 증감 출력 예측 [3점]

다음 코드의 출력 결과를 **네 줄 모두** 쓰시오. 특히 `*p++` 와 `*++p` 의 차이를 설명하시오.

```c
#include <stdio.h>

int main(void)
{
    int a[5] = {2, 4, 6, 8, 10};
    int *p = a;

    printf("%d\n", *p++);
    printf("%d\n", *p);
    printf("%d\n", *++p);
    printf("%d\n", *p + *a);

    return 0;
}
```

### 2번. ★ 포인터 킬러 - 포인터를 반환하는 함수 [5점]

다음 코드의 출력 결과를 쓰고, (1) 함수가 `int *`(포인터)를 반환한다는 것의 의미, (2) `m - a`가 인덱스 `1`이 되는 이유, (3) `*m = 0;` 한 줄로 `main`의 배열이 바뀌는 이유를 설명하시오. (배열에 `9`가 두 개인데 왜 index가 `1`인지도 함께)

```c
#include <stdio.h>

int *find_max(int *arr, int n)
{
    int *maxp = arr;
    for (int i = 1; i < n; i++) {
        if (arr[i] > *maxp)
            maxp = &arr[i];
    }
    return maxp;
}

int main(void)
{
    int a[5] = {3, 9, 2, 9, 5};

    int *m = find_max(a, 5);
    printf("max=%d\n", *m);
    printf("index=%d\n", (int)(m - a));

    *m = 0;
    for (int i = 0; i < 5; i++)
        printf("%d ", a[i]);
    printf("\n");

    return 0;
}
```

### 4번. 함수 - static 변수와 한 식 안의 두 번 호출 [4점]

다음 코드의 출력 결과를 쓰고, 세 번째 출력이 그렇게 나오는 과정을 `static` 변수와 함께 설명하시오.

#include <stdio.h>

int next_id(void)

    printf("%d\n", next_id() + next_id());

### 5번. 문자열 - 포인터로 문자열 순회 [4점]

다음 코드의 출력 결과를 쓰시오. 그리고 (1) `while (*p != '\0')`가 문자열의 끝을 어떻게 아는지, (2) 여기서 `char *s = "..."`로 선언했는데 `s[0] = 'h';`를 하면 왜 위험한지 설명하시오.

```c
#include <stdio.h>

int main(void)
{
    char *s = "Hello, World";
    int upper = 0;
    char *p = s;

    while (*p != '\0') {
        if (*p >= 'A' && *p <= 'Z')
            upper++;
        p++;
    }

    printf("%d\n", upper);
    printf("%d\n", (int)(p - s));

    return 0;
}
```

### 6번. 구조체 - 구조체 배열 + 함수 + 평균 [4점]

다음 코드의 출력 결과를 쓰고, (1) 구조체 배열을 함수에 넘길 때 무엇이 전달되는지, (2) `return (double)total / n;` 에서 `(double)` 형변환이 **왜 꼭 필요한지**(없으면 어떻게 되는지) 설명하시오.

```c
#include <stdio.h>

struct student {
    char name[20];
    int score;
};

double average(struct student *s, int n)
{
    int total = 0;
    for (int i = 0; i < n; i++)
        total += s[i].score;
    return (double)total / n;
}

int main(void)
{
    struct student list[3] = {
        {"A", 80}, {"B", 95}, {"C", 70}
    };

    printf("%.1f\n", average(list, 3));

    return 0;
}
```

### 7번. ★ 버그 찾기 - 무엇이 빠졌는가 [3점]

다음 코드는 `src`의 문자열을 `dst`로 한 글자씩 복사하려는 것이다. 그런데 출력하면 종종 `hello` 뒤에 이상한 문자가 붙어 나온다. **무엇이 빠졌는지 설명하고, 한 줄을 추가/수정**해서 고치시오.

```c
#include <stdio.h>

int main(void)
{
    char dst[10];
    char src[] = "hello";
    int i;

    for (i = 0; src[i] != '\0'; i++)
        dst[i] = src[i];

    printf("%s\n", dst);

    return 0;
}
```

## 정답 및 해설

### 1번 [3점]

출력:
```text
2
4
6
8
```
해설:
- `*p++` 는 `*(p++)` 이다. 후위 증가라 **현재 `*p`(=a[0]=2)를 먼저 사용**하고, 그 다음 `p`가 a[1]로 이동한다 → `2` 출력.
- `*p` : 이제 `p`는 a[1] → `4`.
- `*++p` 는 전위 증가라 **`p`를 먼저 a[2]로 옮긴 뒤** 값을 꺼낸다 → `6`.
- `*p + *a` : `p`는 a[2]=6, `*a`는 a[0]=2 → `8`.

부분 점수: 네 줄 출력 각 0.5점(2점) + `*p++`(쓰고 나서 이동) vs `*++p`(이동 후 사용) 차이 설명 1점.

---

### 2번 [5점]

출력:
```text
max=9
index=1
3 0 2 9 5 
```
해설:
- `find_max`는 최댓값이 들어있는 칸의 **주소(포인터)** 를 반환한다. 그 포인터 `m`을 `*m`으로 풀면 최댓값 `9`.
- 비교가 `>`(초과)라서 **같은 값이면 갱신하지 않는다.** 그래서 9가 두 개여도 **먼저 나온 a[1]** 의 주소가 남는다.
- `m - a` 는 포인터끼리 빼면 **인덱스 차이**가 된다. `m`이 a[1], `a`가 a[0] → `1`.
- `*m = 0;` 은 그 주소(=a[1])의 원본 값을 0으로 바꾼다 → 배열이 `{3, 0, 2, 9, 5}`.

부분 점수: 출력 3개 정확 2점 / 포인터 반환 의미 1점 / `m - a`가 인덱스라는 설명 1점 / `*m=0`이 원본 수정 + 중복 9에서 index=1 이유 1점.

### 3번 [4점]

정답 예시:
```c
#include <stdio.h>

void rotate(int *a, int *b, int *c)
{
    int tmp = *c;   // 마지막 값을 먼저 보관
    *c = *b;
    *b = *a;
    *a = tmp;
}

int main(void)
{
    int x = 1, y = 2, z = 3;
    rotate(&x, &y, &z);
    printf("x=%d y=%d z=%d\n", x, y, z);   // x=3 y=1 z=2
    return 0;
}
```
해설:
- 그냥 순서대로 덮어쓰면 값이 날아가므로, 끝값 `*c`를 임시 변수에 보관한 뒤 `*c←*b`, `*b←*a`, `*a←tmp` 순으로 회전한다.
- 출력: `x=3 y=1 z=2`.

부분 점수: 포인터 매개변수 선언 1점 / 임시 변수로 덮어쓰기 방지 1점 / 회전 대입 순서 정확 1점 / `main`에서 `&x,&y,&z` 전달 + 출력 1점.

### 4번 [4점]

출력:
```text
101
102
207
```
해설:
- `id`는 `static`이라 호출해도 사라지지 않고 누적된다. 첫 호출 `101`, 두 번째 `102`.
- 세 번째 줄 `next_id() + next_id()` 은 함수를 **두 번** 호출한다. `id`가 `103`, `104`로 증가하고 두 반환값을 더해 `103 + 104 = 207`. (두 호출의 순서와 무관하게 합은 207)

부분 점수: 첫·둘째 줄 101, 102 → 1.5점 / 세 번째 줄 207 → 1.5점 / static 누적 설명 1점.

### 5번 [4점]

출력:
```text
2
12
```
해설:
- 대문자는 `H`, `W` 두 개 → `upper = 2`.
- `"Hello, World"` 는 12글자 → `p`가 끝(`'\0'`)까지 이동했으므로 `p - s = 12`.
- (1) C 문자열은 끝에 널 문자 `'\0'`가 있어서, `*p != '\0'` 가 거짓이 되는 순간(=끝) 반복이 멈춘다.
- (2) `char *s = "..."`는 읽기 전용 문자열 상수를 가리킨다. `s[0] = 'h';`처럼 내용을 바꾸려 하면 실행 중 오류(크래시)가 난다. (배열 `char s[]`로 선언했다면 수정 가능)

부분 점수: 출력 2, 12 각 1점(2점) / `'\0'`로 끝을 안다는 설명 1점 / 문자열 상수 수정 위험 설명 1점.

### 6번 [4점]

출력:
```text
81.7
```
해설:
- 점수 합 `80 + 95 + 70 = 245`. 평균 `245 / 3 = 81.666...` → `%.1f` 로 `81.7`.
- (1) 구조체 배열을 함수에 넘기면 배열의 **주소(첫 원소 포인터)** 가 전달된다. 그래서 `s[i].score`로 원본에 접근한다.
- (2) `total`과 `n`이 둘 다 `int`라 `total / n`만 쓰면 **정수 나눗셈(245/3 = 81)** 이 되어 소수점이 사라진다. `(double)`로 형변환해야 `81.666...`이 살아남아 `81.7`이 나온다.

부분 점수: 출력 `81.7` 2점 / 배열 넘기면 주소 전달 설명 1점 / `(double)` 없으면 정수나눗셈(81.0) 된다는 설명 1점.

### 7번 [3점]

무엇이 빠졌나:
- 복사 루프가 `'\0'`은 복사하지 않고 끝난다. `dst`에 **널 종료 문자(`'\0'`)를 넣지 않아서**, `printf("%s")`가 문자열의 끝을 못 찾고 `dst` 뒤의 쓰레기 메모리까지 출력한다.

고친 코드 (루프 뒤 한 줄 추가):
```c
    for (i = 0; src[i] != '\0'; i++)
        dst[i] = src[i];
    dst[i] = '\0';          // ★ 널 문자로 끝을 표시
    printf("%s\n", dst);
```
부분 점수: 원인을 "널 종료(`'\0'`) 누락"으로 설명 1.5점 / `dst[i] = '\0';` 추가로 수정 1.5점.

### 8번 [3점]

B

부분 점수: (1) 출력 `B` + 조건부 컴파일 설명 1.5점 / (2) "열기 실패 시 NULL 반환 → 크래시 방지" 설명 1.5점.

### 1번. 종합 - 코드 보고 예상 출력값 쓰기 [3점]

다음 코드의 출력 결과를 **네 줄 모두** 쓰시오. 특히 `p++` 이후 `p`가 무엇을 가리키는지 한 줄로 설명하시오.

```c
#include <stdio.h>

int main(void)
{
    int arr[4] = {5, 10, 15, 20};
    int *p = arr;

    p++;
    printf("%d\n", *p);
    printf("%d\n", *(p + 1));
    printf("%d\n", arr[3] - *p);

    char ch = 'a' + 2;
    printf("%c\n", ch);

    return 0;
}
```

### 2번. ★ 포인터 킬러 - 두 포인터로 배열 뒤집기 [5점]

다음 코드의 출력 결과를 쓰고, (1) `arr + n - 1`이 무엇을 가리키는지, (2) `left`, `right` 포인터로 어떻게 배열이 뒤집히는지, (3) 함수에 `a`만 넘겼는데 `main`의 배열이 바뀌는 이유를 설명하시오.

```c
#include <stdio.h>

void reverse(int *arr, int n)
{
    int *left = arr;
    int *right = arr + n - 1;

    while (left < right) {
        int tmp = *left;
        *left = *right;
        *right = tmp;
        left++;
        right--;
    }
}

int main(void)
{
    int a[5] = {1, 2, 3, 4, 5};

    reverse(a, 5);

    for (int i = 0; i < 5; i++)
        printf("%d ", a[i]);
    printf("\n");

    return 0;
}
```

### 4번. 함수 - 재귀 함수 추적 [4점]

다음 코드의 출력 결과를 쓰고, `sum(5)`가 호출되었을 때 `sum` 함수가 **총 몇 번** 호출되는지와 **종료 조건(base case)** 이 무엇인지 설명하시오.

```c
#include <stdio.h>

int sum(int n)
{
    if (n == 0)
        return 0;
    return n + sum(n - 1);
}

int main(void)
{
    printf("%d\n", sum(5));
    return 0;
}
```

### 5번. 문자열 - 문자 탐색과 널 문자 [4점]

다음 코드의 출력 결과를 쓰시오. 그리고 (1) `for` 반복문이 `s[i] != '\0'` 에서 멈추는 이유, (2) `char s[] = "banana"`(배열)와 `char *p = "banana"`(포인터)의 내용 **수정 가능 여부** 차이를 설명하시오.

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "banana";
    int count = 0;

    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == 'a')
            count++;
    }

    printf("len=%d\n", (int)strlen(s));
    printf("a count=%d\n", count);

    return 0;
}
```

### 6번. 구조체 - 구조체 포인터와 멤버 접근 [4점]

다음 코드의 출력 결과를 쓰고, **함수 안에서는 `p->x`로 접근하는데 `main`에서는 `p.x`로 접근하는 이유**를 설명하시오.

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

void move(struct point *p, int dx, int dy)
{
    p->x += dx;
    p->y += dy;
}

int main(void)
{
    struct point p = {2, 3};

    move(&p, 5, -1);

    printf("(%d, %d)\n", p.x, p.y);

    return 0;
}
```

## 정답 및 해설

### 1번 [3점]

출력:
```text
10
15
10
c
```
해설:
- `p = arr` 후 `p++` → `p`는 `arr[1]`을 가리킨다. 그래서 `*p = 10`.
- `*(p + 1)` = `arr[2]` = `15`.
- `arr[3] - *p` = `20 - 10` = `10`.
- `ch = 'a' + 2` → 'a'(97) + 2 = 99 = `'c'`. `%c`로 출력하면 `c`.

부분 점수: 네 줄 출력 각 0.5점(총 2점) + `p++` 후 `arr[1]`을 가리킨다는 설명 1점.

---

### 2번 [5점]

출력:
```text
5 4 3 2 1 
```
해설:
- `arr + n - 1`은 배열의 **마지막 원소(`arr[4]`)의 주소**다.
- `left`는 앞에서, `right`는 뒤에서 시작해 두 값을 교환하고 가운데로 좁혀온다(`left++`, `right--`). `left < right`가 깨지면 종료 → 배열이 뒤집힌다.
- `reverse(a, 5)`에서 배열 이름 `a`는 주소이므로 함수는 원본을 직접 가리킨다. 따라서 `main`의 `a`가 `{5,4,3,2,1}`로 바뀐다.

부분 점수: 출력 정확 2점 / `arr+n-1`이 마지막 원소 주소 1점 / 두 포인터 교환·수렴 설명 1점 / 배열=주소라 원본이 바뀜 설명 1점.

### 3번 [4점]

정답 예시:
```c
#include <stdio.h>

void minmax(int a, int b, int *pmin, int *pmax)
{
    if (a < b) { *pmin = a; *pmax = b; }
    else       { *pmin = b; *pmax = a; }
}

int main(void)
{
    int mn, mx;
    minmax(7, 3, &mn, &mx);
    printf("min=%d max=%d\n", mn, mx);   // min=3 max=7
    return 0;
}
```
해설:
- `return`은 값을 **하나만** 돌려줄 수 있다. 결과가 2개(최소·최대)이므로, 변수의 주소(`&mn`, `&mx`)를 넘기고 함수 안에서 `*pmin`, `*pmax`로 원본에 직접 써넣는다.

부분 점수: 포인터 매개변수 선언 1점 / 대소 비교 후 `*pmin`,`*pmax`에 저장 1.5점 / `main`에서 `&mn`,`&mx` 전달 1점 / 결과가 2개라 포인터로 받는다는 설명 0.5점.

### 4번 [4점]

출력:
```text
15
```
해설:
- `sum(5) = 5 + sum(4) = 5+4+3+2+1+0 = 15`.
- 호출 횟수: `sum(5), sum(4), sum(3), sum(2), sum(1), sum(0)` → **총 6번**.
- 종료 조건: `n == 0`일 때 `0`을 반환하며 더 이상 자기 자신을 부르지 않는다. (이게 없으면 무한 재귀)

부분 점수: 출력 15 → 1.5점 / 호출 6번 → 1점 / 종료 조건 `n==0` 설명 → 1.5점.

### 5번 [4점]

출력:
```text
len=6
a count=3
```
해설:
- `"banana"`는 길이 6. `'a'`는 인덱스 1, 3, 5에 있어 `count = 3`.
- (1) C 문자열은 끝에 널 문자 `'\0'`가 있다. `s[i] != '\0'`는 그 끝을 만나면 거짓이 되어 반복이 멈춘다.
- (2) `char s[] = "banana"`는 배열에 복사된 것이라 `s[0]='B';`처럼 **수정 가능**. `char *p = "banana"`는 읽기 전용 문자열 상수를 가리켜 `p[0]='B';`를 하면 **실행 중 오류**가 난다.

부분 점수: 출력 두 줄 2점 / `'\0'`에서 멈추는 이유 1점 / `char[]` vs `char*` 차이 1점.

### 6번 [4점]

출력:
```text
(7, 2)
```
해설:
- `move(&p, 5, -1)`로 `p`의 주소를 넘긴다. 함수 안 `p`는 **구조체 포인터**라 멤버 접근에 `->`를 쓴다(`p->x += dx`). `p->x`는 `(*p).x`와 같다.
- `main`의 `p`는 **구조체 변수**라 `.`로 접근한다(`p.x`). 주소를 넘겨 원본을 고쳤으므로 `x: 2→7`, `y: 3→2`.

부분 점수: 출력 `(7, 2)` 2점 / 포인터는 `->`, 변수는 `.`라는 설명 1.5점 / `p->x == (*p).x` 언급 0.5점.

### 7번 [3점]

무엇이 잘못되었나:
- `s == "admin"`은 문자열의 **내용**이 아니라 **주소**를 비교한다. 배열 `s`의 주소와 문자열 상수 `"admin"`의 주소는 절대 같지 않아 조건이 항상 거짓 → 항상 "일반 사용자"가 출력된다.
- C에서 문자열 내용 비교는 `strcmp`로 해야 하며, 같으면 `0`을 반환한다.

고친 코드:
```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[20];

    printf("이름 입력: ");
    scanf("%s", s);

    if (strcmp(s, "admin") == 0)
        printf("관리자\n");
    else
        printf("일반 사용자\n");

    return 0;
}
```
부분 점수: 원인을 "주소 비교라서"로 설명 1.5점 / `strcmp(s, "admin") == 0`으로 수정 1점 / `#include <string.h>` 포함 0.5점.

(2) 정답 예시:

```c
int *p = (int *)malloc(5 * sizeof(int));   // 동적 할당

```
부분 점수: (1) w=덮어쓰기 / a=이어쓰기 각 0.75점(총 1.5점) / (2) `malloc(5*sizeof(int))` + `(int*)` 형변환 1점, `free(p)` 0.5점.

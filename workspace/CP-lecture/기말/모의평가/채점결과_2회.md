## 핵심 오답 정리

### 3번 (감점 1.5) — 회전 "방향"이 반대 + `tmp` 선언

문제 요구: **`a←원래 c`, `b←원래 a`, `c←원래 b`** → x=1,y=2,z=3 이면 결과는 `3 1 2`.

너의 코드는 방향이 반대로 돌아간다:
```c
*tmp = *a;   // tmp ← a(=1)
*a = *b;     // a ← b(=2)
*b = *c;     // b ← c(=3)
*c = *tmp;   // c ← a(=1)
// 결과: 2 3 1  (a←b, b←c, c←a 방향)
```
요구한 방향대로면 **마지막 값(c)을 먼저 백업**해야 한다:
```c
void rotate(int *a, int *b, int *c)
{
    int tmp = *c;   // ★ int (포인터 아님!) 으로 선언, 마지막 값부터 백업
    *c = *b;        // c ← b
    *b = *a;        // b ← a
    *a = tmp;       // a ← (원래 c)
}
// 결과: 3 1 2
```
추가로 **`int *tmp`(포인터)로 선언하고 `*tmp`로 쓰면 안 된다.** 초기화 안 된 포인터를 역참조하면 엉뚱한 주소에 쓰는 거라 크래시 난다. 임시 저장용은 **`int tmp;`(그냥 정수)** 로. (혹시 `int tmp`로 쓴 건데 별표처럼 보인 거면 방향만 고치면 됨)

### 6번 (감점 0.8) — `%.1f`는 반올림

`245 / 3 = 81.6666...` 까지는 정확히 계산했어. 그런데 `printf("%.1f", ...)`는 소수 둘째 자리에서 **반올림**한다 → `81.666...` → **`81.7`** (네가 적은 `81.6`은 버림한 값). `%.Nf`는 버림이 아니라 반올림이라는 것만 기억하면 돼.

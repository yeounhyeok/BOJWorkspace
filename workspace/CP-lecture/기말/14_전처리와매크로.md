# 14장 전처리와 매크로 (Preprocessor & Macro)

> 예제 코드: [src/14_전처리와매크로/](src/14_전처리와매크로/)

## 1. 전처리기란
- **컴파일 이전**에 소스 코드를 다루는 단계. `#` 으로 시작하는 줄(지시자)을 처리.
- 핵심은 **단순 텍스트 치환** (값을 계산하는 게 아님!).

## 2. #define 단순 매크로 (상수 정의)
```c
#define PI 3.1415
#define SIZE 100
```
- 컴파일 전에 코드의 모든 `PI` 를 `3.1415` 로 **그대로 바꿔치기**.
- 장점: 값 한 곳만 고치면 전체 반영, 가독성.

## 3. 함수형 매크로 ★★ (가장 잘 나옴)
```c
#define SQUARE(x) ((x) * (x))
```
- [macro1.c](src/14_전처리와매크로/macro1.c) : `SQUARE(3)`, `SQUARE(1.2)`, `SQUARE(2+3)`, `SQUARE(x)` 다 됨.
- ⚠️ **괄호를 꼭 씌우는 이유** (시험 함정!):
  - `#define SQUARE(x) x*x` 로 하면 `SQUARE(2+3)` → `2+3*2+3` = **11** (틀림!)
  - `#define SQUARE(x) ((x)*(x))` 로 해야 `((2+3)*(2+3))` = **25** (정답)
  - → 매크로 인자와 전체를 **괄호로 감싸야** 연산자 우선순위 문제 안 생김.
- [func_macro.c](src/14_전처리와매크로/func_macro.c) : `#define CIRCLE_AREA(r) (PI*r*r)` 원 넓이
- [bit_macro.c](src/14_전처리와매크로/bit_macro.c) ★ : 비트 조작 매크로
  ```c
  #define SETBIT(x,n)   ((x) |= (1<<(n)))   // n번째 비트 1로
  #define CLEARBIT(x,n) ((x) &= ~(1<<(n)))  // n번째 비트 0으로
  #define TESTBIT(x,n)  ((x) & (1<<(n)))    // n번째 비트 확인
  ```
- [macro_lab1.c](src/14_전처리와매크로/macro_lab1.c) : `#define and &&` / `#define or ||` 처럼 연산자도 치환 가능 (졸업 판정 예제)

> **함수 vs 매크로**: 매크로는 호출 오버헤드 없이 빠르지만, 단순 치환이라 부작용(side effect) 주의. 함수는 타입 검사·안전하지만 호출 비용 있음.

## 4. 조건부 컴파일 #ifdef / #else / #endif ★
```c
#define DEBUG
#ifdef DEBUG
    printf("디버깅 모드\n");   // DEBUG 가 정의돼 있으면 이 줄 컴파일
#endif
```
- [macro3.c](src/14_전처리와매크로/macro3.c) : `#ifdef LINUX ... #else ... #endif` → 정의 여부에 따라 다른 코드 컴파일
- [func_macro.c](src/14_전처리와매크로/func_macro.c) : `#ifdef DEBUG` 로 디버그 출력 on/off
- 용도: OS별/디버그용 코드 분기, 중복 포함 방지(`#ifndef` 헤더 가드).

## 5. 자주 쓰는 전처리 지시자 정리
| 지시자 | 의미 |
|--------|------|
| `#include` | 헤더 파일 포함 |
| `#define` | 매크로 정의 |
| `#undef` | 매크로 정의 해제 |
| `#ifdef / #ifndef` | ~가 정의됨/안 됨 이면 |
| `#if / #else / #elif / #endif` | 조건부 컴파일 |

## 🎯 시험 포인트 요약
- 전처리 = **컴파일 전 텍스트 치환** (계산 아님)
- `#define` 상수 vs **함수형 매크로**
- ★ **매크로 괄호 안 씌우면 생기는 오류** (`SQUARE(2+3)` 문제) — 서술/계산형 단골
- `#ifdef / #else / #endif` 조건부 컴파일 동작
- 비트 매크로 SETBIT/CLEARBIT/TESTBIT 의미
